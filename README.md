# Добро пожаловать

> ### Chatterfy - это платформа для создания AI чат-ботов, автоматизации общения с клиентами и анализа трафика.

### Chatterfy объединяет **AI-ботов**, **CRM** и **Tracker** в одной системе.

{% hint style="success" %}
Платформа помогает автоматизировать общение с клиентами, обрабатывать лиды и видеть путь пользователя от клика до продажи.
{% endhint %}

### Главные возможности:

* **AI-боты** — автоматическая обработка диалогов 24/7.
* **CRM** — чаты, лиды, статусы, теги и рассылки.
* **Tracker** — аналитика трафика, событий и конверсий.
