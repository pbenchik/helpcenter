# Что такое Chatterfy

> ### Chatterfy объединяет **AI-ботов**, **CRM** и **Tracker** в одной системе. Платформа помогает автоматизировать общение с клиентами, обрабатывать лиды и отслеживать путь пользователя от клика до продажи.

### Что входит в Chatterfy

{% tabs %}
{% tab title="AI-боты" %}
{% hint style="info" %}
Благодаря гибким настройкам воронок и возможности подключить Искусственный Интеллект, Вы можете простраивать разнообразные сценарии общения с Вашими клиентами - назначать теги, проводить A/B тестирования гипотез, распределять трафик по обработчикам и многое другое.\
ИИ может не только общаться, но и распознавать скриншоты, голосовые сообщения, кружки.
{% endhint %}
{% endtab %}

{% tab title="CRM" %}
{% hint style="info" %}
CRM нужна для общения с Вашими клиентами.\
В ней Вы видите все диалоги, фильтрацию по различным гибким условиям, возможность вносить или изменять информацию в карточке клиента - назначать менеджеров, менять шаг или теги у пользователя (и даже отправлять события по типу регистрации и депозита).

Templates позволяют делать заготовленные шаблонные сообщения для операторов, а функция встроенного ИИ переводчика в диалоговом окне позволяет не переводить их предварительно на все языки.

Помимо этого, с помощью CRM Вы сможете сделать рассылки, тексты которых предварительно уникализируете с помощью ИИ. А также массовые действия - например, назначить всем пользователям статус продажи.
{% endhint %}
{% endtab %}

{% tab title="Tracker" %}
{% hint style="info" %}
Tracker позволяет эффективно отслеживать метрики. В нем Вы можете создать кампанию, чтобы получить уникальную ссылку для перехода пользователей из разных источников трафика.\
С помощью разделов Dashboards и Analytics Вы сможете просматривать статистику по своим кампаниям - клики, подписки, диалоги, регистрации, депозиты и ре-депозиты.

Помимо этого, трекер позволяет подключить получение событий из Вашей партнерской программы. Постбэки - это удобный инструмент, позволяющий получать регистрации, депозиты и другие события автоматически при совершении лидом целевого действия.
{% endhint %}
{% endtab %}

{% tab title="Итог" %}
{% hint style="info" %}
Chatterfy - это универсальный инструмент, для работы с клиентами и трафиком, включающий в себя CRM, автоматизацию, аналитику и другие функции.

С помощью него Вы можете как простроить сложную воронку круглосуточной продажи с использованием ИИ, так и распределить нагрузку внутри уже существующего отдела обработки.

Использование Chatterfy поможет масштабировать Ваши проекты и оптимизировать нагрузки на отделы продаж и работы с клиентами.
{% endhint %}
{% endtab %}
{% endtabs %}

{% hint style="info" %}
Chatterfy особенно полезен, если вам нужно:

* обрабатывать лидов **24/7**
* сократить нагрузку на операторов
* видеть эффективность трафика в одном интерфейсе
{% endhint %}

Перейдите в раздел быстрого старта. Выберите подключение бота или аккаунта. Затем выполните шаги подключения для нужного канала.

### Настраивают логику общения

{% hint style="info" %}
Внутри платформы создаются сценарии, автодействия и AI-ответы.

Откройте конструктор Flow Settings. Создайте новый flow. Добавьте сообщения, условия, задержки и AI Reply в нужной последовательности.

### Обрабатывают лиды в CRM

{% hint style="info" %}
Все диалоги, статусы и данные по клиентам хранятся внутри CRM.

Зайдите в CRM и откройте Messenger. Назначайте менеджеров, меняйте статусы, ставьте теги и ведите клиента по воронке.

{% hint style="info" %}
