# Как создать аккаунт

Чтобы начать работу с Chatterfy, нужно зарегистрировать аккаунт, создать компанию и активировать её.

### Видео

Короткая инструкция по регистрации, созданию компании и активации.

{% embed url="https://www.youtube.com/watch?v=UDfceUEnKFs" %}

#### Таймкоды

* `00:13` — Регистрация
* `00:53` — Создание компании

{% hint style="warning" %}
Для активации нужен демо-звонок и первое пополнение от `100 USD`.
{% endhint %}

### Как это работает

После регистрации аккаунта нужно пройти активацию компании.

Активация включает связь с менеджером, демо-звонок и первое пополнение.

### Шаги

1. Перейдите на страницу регистрации: [app.chatterfy.ai/signin](https://app.chatterfy.ai/signin)
2. Укажите `email` и пароль
3. Введите код подтверждения из письма
4. Свяжитесь с менеджером: [t.me/chatterfyai](https://t.me/chatterfyai)
5. Пройдите обязательный демо-звонок
6. Пополните баланс минимум на `100 USD`

### Регистрация

Создайте аккаунт и подтвердите почту.

#### Что дальше

* После регистрации на почту придёт код подтверждения
* Введите его, чтобы завершить создание аккаунта

### Активация компании

После регистрации нужно пройти обязательные шаги для активации.

#### Как это работает

Менеджер помогает активировать аккаунт, объясняет следующие шаги и отвечает на вопросы по платформе.

#### Шаги

1. Напишите менеджеру: [t.me/chatterfyai](https://t.me/chatterfyai)
2. Согласуйте демо-звонок
3. Пройдите демонстрацию платформы
4. Пополните баланс компании

#### Что будет на демо-звонке

* Покажут основные возможности платформы
* Объяснят условия работы
* Разберут ваш кейс
* Ответят на вопросы по настройке

### Пополнение баланса

Первое пополнение завершает активацию компании.

#### Как это работает

Для активации компании нужно внести минимум `100 USD`.

#### Доступные сети

* `ERC20`
* `TRC20`
