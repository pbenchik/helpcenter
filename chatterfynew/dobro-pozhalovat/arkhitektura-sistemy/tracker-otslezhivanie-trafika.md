# Tracker - отслеживание трафика

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2114.png" alt=""><figcaption></figcaption></figure></div>

**Tracker** — это раздел для отслеживания трафика, событий и конверсий.

Он помогает видеть путь пользователя от первого клика до целевого действия.

Tracker нужен, чтобы понимать, какие кампании дают результат, а где трафик теряется.

### Как работает Tracker:

{% stepper %}
{% step %}
### Источник трафика

{% hint style="info" %}
Сначала в Tracker настраивают кампанию и источник трафика.

Это может быть Facebook, Telegram, Google или другой источник.
{% endhint %}
{% endstep %}

{% step %}
### Переход пользователя

{% hint style="info" %}
После запуска рекламы Tracker фиксирует переход пользователя по ссылке.

Система сохраняет параметры кампании, источника и креатива.
{% endhint %}
{% endstep %}

{% step %}
### События и конверсии

{% hint style="info" %}
Дальше Tracker собирает ключевые действия пользователя.

Это могут быть `subscribe`, `contact`, `registration`, `FD` и `RD`.
{% endhint %}
{% endstep %}

{% step %}
### Анализ результата

{% hint style="info" %}
Команда видит, какие кампании приводят регистрации, депозиты и другие целевые действия.

На основе этих данных можно оптимизировать рекламу по реальному результату.
{% endhint %}
{% endstep %}
{% endstepper %}
