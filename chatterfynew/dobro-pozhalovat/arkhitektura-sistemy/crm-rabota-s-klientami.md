# CRM - работа с клиентами

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2112 (1).png" alt=""><figcaption></figcaption></figure></div>

**CRM** — это рабочая зона для общения с клиентами и управления лидами.

Здесь ваша команда ведёт переписку, отслеживает статусы и работает с данными клиента в одном интерфейсе.

CRM объединяет чаты, карточки лидов, события и базу пользователей в одном месте.

### Возможности CRM:

{% stepper %}
{% step %}
### Messenger

{% hint style="info" %}
В **Messenger** команда ведёт переписку с клиентами.

Здесь отвечают на сообщения, меняют статусы и контролируют диалоги.
{% endhint %}
{% endstep %}

{% step %}
### Chat Data

{% hint style="info" %}
В карточке лида хранится основная информация по клиенту.

Здесь смотрят историю, теги, менеджера, статусы и дополнительные данные.
{% endhint %}
{% endstep %}

{% step %}
### Events

{% hint style="info" %}
В этом разделе можно проверить действия пользователя.

Здесь доступны история, логи, AI-запросы, события и конверсии.
{% endhint %}
{% endstep %}

{% step %}
### Users и Mailings

{% hint style="info" %}
CRM помогает работать со всей базой пользователей.

Здесь фильтруют аудиторию, сегментируют её и запускают рассылки.
{% endhint %}
{% endstep %}
{% endstepper %}

### Основные разделы CRM:

<details>

<summary>Messenger</summary>

{% hint style="info" %}
Раздел для работы с чатами и входящими сообщениями.

Здесь команда может:

* вести переписку с клиентами
* менять статусы чатов
* использовать фильтры
* работать с шаблонами и переводчиком
*

    <div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

</details>

{% hint style="info" %}

* назначать менеджера
* работать с тегами
* менять sale status и custom data

    <div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2170 (1).png" alt=""><figcaption></figcaption></figure></div>

    <div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2171.png" alt=""><figcaption></figcaption></figure></div>

* выполнять массовые действия
