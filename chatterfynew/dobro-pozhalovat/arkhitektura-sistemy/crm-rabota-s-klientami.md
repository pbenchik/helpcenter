# CRM - работа с клиентами

### CRM

Это рабочая зона для общения с клиентами и управления лидами.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2112 (1).png" alt=""><figcaption></figcaption></figure></div>

Здесь ваша команда ведёт переписку, отслеживает статусы и работает с данными клиента в одном интерфейсе.

CRM объединяет чаты, карточки лидов, события и базу пользователей в одном месте.

### Возможности CRM

CRM объединяет работу с диалогами, карточками лидов, событиями и базой пользователей.

#### Как это работает

Команда получает входящие сообщения, обрабатывает лида, проверяет данные и работает с аудиторией.

#### Шаги

1. Ведут переписку в **Messenger**
2. Работают с данными лида в **Chat Data**
3. Проверяют историю и события
4. Фильтруют базу и запускают рассылки

### Messenger

Раздел для работы с чатами и входящими сообщениями.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure></div>

#### Что можно делать

* вести переписку с клиентами
* менять статусы чатов
* использовать фильтры
* работать с шаблонами и переводчиком

### Chat Data

Раздел с данными по конкретному клиенту.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2170 (1).png" alt=""><figcaption></figcaption></figure></div>

#### Что можно делать

* смотреть **Flow** и **Step**
* назначать менеджера
* работать с тегами
* менять `sale status` и `custom data`

### История действий в диалоге

Раздел для просмотра истории действий по чату.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (93).png" alt=""><figcaption></figcaption></figure></div>

#### Что доступно

* история переписки
* логи
* `AI`-запросы

### Events

Раздел с событиями пользователя и их типами.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2171.png" alt=""><figcaption></figcaption></figure></div>

#### Что помогает делать

* видеть действия пользователя
* отслеживать конверсии
* проверять ручную отправку событий

### Users и Mailings

Эти разделы нужны для работы с базой и коммуникацией.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>

#### Что можно делать

* фильтровать пользователей
* выполнять массовые действия
* экспортировать `CSV`
* запускать массовые и `AI`-рассылки

{% hint style="info" %}
Базовая логика CRM простая: входящие диалоги → обработка лида → анализ данных → работа с базой.
{% endhint %}
