# Быстрый старт

В этом разделе собраны основные шаги запуска и базовой настройки системы.

### Как это работает

Быстрый старт ведёт по базовой последовательности настройки Chatterfy.

Сначала создают рабочее пространство и настраивают доступы. Затем подключают бота и Tracker.
