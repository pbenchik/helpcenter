# Безопасность

Безопасность в Chatterfy строится на правильной настройке ролей и доступов.

Чем шире права у сотрудника, тем больше данных и разделов он видит внутри системы.

### Что важно контролировать

В первую очередь нужно контролировать базовые уровни доступа.

#### Что проверять

* роли на уровне **Company**
* доступ к конкретным **Spaces**
* доступ к `Tracker`
* список сотрудников с расширенными правами

### Как работает безопасность в системе

Безопасность строится вокруг роли и точечных доступов.

#### Шаги

1. Сотруднику назначают роль
2. Ему открывают только нужные разделы
3. Доступы регулярно проверяют

### Основные правила безопасности

Ниже — базовые правила, которые помогают снизить риски.

### Минимально необходимый доступ

Сотруднику нужно выдавать только тот доступ, который нужен для его задач.

#### Что это даёт

* снижает риск ошибок
* ограничивает доступ к лишним данным
* упрощает контроль работы команды

### Какие роли выдавать осторожно

Без необходимости не стоит выдавать расширенные роли.

#### Роли с повышенным доступом

* `Manager`
* `Admin`
* `Owner`

{% hint style="danger" %}
Эти роли подходят только тем сотрудникам, которым действительно нужен расширенный доступ.
{% endhint %}

### Что видят пользователи с широким доступом

Пользователи с ролями `Owner` и `Admin` обычно получают доступ к большей части системы.

#### Обычно доступно

* все боты
* все диалоги
* вся статистика
* все рекламные кампании

### Базовые рекомендации

Эти правила помогают выстраивать доступы безопаснее.

#### Рекомендации

* выдавайте минимально необходимую роль
* не открывайте доступ ко всем **Spaces** без причины
* ограничивайте доступ к `Tracker` только нужным сотрудникам
* регулярно проверяйте, какие роли уже назначены

{% hint style="warning" %}
Если сотруднику не нужен полный доступ, не назначайте ему `Admin` или `Owner`.
{% endhint %}
