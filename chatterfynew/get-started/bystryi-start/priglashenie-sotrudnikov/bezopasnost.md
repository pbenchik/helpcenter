# Безопасность

> #### Безопасность в Chatterfy строится на правильной настройке ролей и доступов.

Чем шире права у сотрудника, тем больше данных и разделов он видит внутри системы.

### Что важно контролировать:

{% hint style="info" %}
В первую очередь стоит контролировать:

* роли на уровне Company
* доступ к конкретным Spaces
* доступ к Tracker
* список сотрудников с расширенными правами
{% endhint %}

### Как работает безопасность в системе:

{% stepper %}
{% step %}
#### Сотруднику назначают роль

{% hint style="warning" %}
Роль определяет базовый уровень доступа внутри компании.
{% endhint %}
{% endstep %}

{% step %}
#### Ему открывают только нужные разделы

{% hint style="warning" %}
После этого сотруднику выдают доступ только к тем Spaces и инструментам, которые нужны для работы.
{% endhint %}
{% endstep %}

{% step %}
#### Доступы регулярно проверяют

{% hint style="warning" %}
Если задачи меняются, роли и ограничения нужно пересматривать.
{% endhint %}
{% endstep %}
{% endstepper %}

### Основные правила безопасности:

<details>

<summary>Минимально необходимый доступ</summary>

{% hint style="info" %}
Выдавайте сотруднику только тот доступ, который нужен для его задач.

Это помогает:

* снизить риск ошибок
* ограничить доступ к лишним данным
* проще контролировать работу команды
{% endhint %}

</details>

<details>

<summary>Какие роли выдавать осторожно</summary>

{% hint style="info" %}
Без необходимости не стоит выдавать роли:

* `Manager`
* `Admin`
* `Owner`
{% endhint %}

{% hint style="danger" %}
Эти роли подходят только тем сотрудникам, которым действительно нужен расширенный доступ.
{% endhint %}

</details>

<details>

<summary>Что видят пользователи с широким доступом</summary>

{% hint style="info" %}
Пользователи с ролями `Owner` и `Admin` обычно получают доступ:

* ко всем ботам
* ко всем диалогам
* ко всей статистике
* ко всем рекламным кампаниям
{% endhint %}

</details>

<details>

<summary>Базовые рекомендации</summary>

{% hint style="info" %}
Чтобы снизить риски:

* выдавайте минимально необходимую роль
* не открывайте доступ ко всем Spaces без причины
* ограничивайте доступ к Tracker только нужным сотрудникам
* регулярно проверяйте, какие роли уже назначены
{% endhint %}

</details>

{% hint style="info" %}
Базовый принцип безопасности: сначала минимальная роль, затем только нужные доступы в Space и Tracker.
{% endhint %}

{% hint style="warning" %}
Если сотруднику не нужен полный доступ, не назначайте ему `Admin` или `Owner`.
{% endhint %}
