# Приглашение сотрудников

В этом разделе показано, как добавить сотрудников в компанию и настроить им доступы.

### Что важно знать до приглашения

По умолчанию приглашённый пользователь получает базовые настройки.

#### Что получает пользователь

* роль **Operator**
* отсутствие доступа к **Space**
* отсутствие доступа к **Tracker**

{% hint style="info" %}
Сначала пригласите сотрудника, затем отдельно выдайте доступ к нужным **Spaces** и **Tracker**.
{% endhint %}

### Приглашение по email

Пошаговый сценарий приглашения через `email`.

#### Шаги

1. Перейдите в **Company** → **Users**
2. Нажмите **Invite user**
3. Откройте блок **Invite by email**
4. Укажите `email` пользователя
5. Выберите роль
6. Нажмите **Send invites**

### Приглашение по ссылке

Альтернативный сценарий приглашения через ссылку.

#### Шаги

1. Перейдите в **Company** → **Users**
2. Нажмите **Invite user**
3. В блоке **Invite by link** выберите роль пользователя
4. Скопируйте ссылку
5. Отправьте её сотруднику

### Что настроить после приглашения

После входа сотрудника обычно настраивают дополнительные доступы.

#### Что проверить

* роль на уровне компании
* доступ к нужным **Spaces**
* доступ к **Tracker** при необходимости
* ограничения по безопасности

{% hint style="warning" %}
Не выдавайте расширенные роли без необходимости. Доступы лучше открывать только под рабочие задачи.
{% endhint %}

### Как это связано с ролями

После приглашения сотруднику обычно назначают роль и проверяют ограничения.

#### Следующие шаги

1. Откройте [Роли Company](roli-company.md)
2. Проверьте [Безопасность](bezopasnost.md)
3. Выдайте доступ только к нужным **Spaces** и `Tracker`
