# Приглашение сотрудников

> ### В этом разделе подробная инструкцию по добавлению сотрудников в компанию и настраиванию им доступов

### Что важно знать до приглашения:

{% hint style="info" %}
По умолчанию приглашённый пользователь:

* получает роль **Operator**
* не имеет доступа ни к одному **Space**
* не имеет доступа к **Tracker**

После принятия приглашения администратор вручную настраивает доступы.
{% endhint %}

{% hint style="info" %}
Сначала пригласите сотрудника, затем отдельно выдайте доступ к нужным Spaces и Tracker.
{% endhint %}

### Что настроить после приглашения:

После входа сотрудника обычно настраивают:

* роль на уровне компании
* доступ к нужным Spaces
* доступ к Tracker при необходимости
* ограничения по безопасности

{% hint style="warning" %}
Не выдавайте расширенные роли без необходимости. Доступы лучше открывать только под рабочие задачи.
{% endhint %}
