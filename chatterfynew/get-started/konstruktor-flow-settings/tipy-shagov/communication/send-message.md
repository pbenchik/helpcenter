# Send message

> ### Send Message - это шаг для отправки готовых сообщений.

Здесь можно отправлять текст, медиа, файлы, голосовые, видеокружки и сообщения с кнопками.

<div align="center" data-full-width="false" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Frame 2139 (5).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
С помощью Send Message можно:

* Отправлять обычный текст
* Добавлять фото, видео и документы
* Отправлять голосовые и видеокружки
* Добавлять inline buttons и keyboard к сообщениям
* Собирать цепочки из нескольких сообщений
* Настраивать пуши, если пользователь не ответил

Этот шаг подходит для фиксированных сообщений, инструкций и догрева.
{% endhint %}

### Settings:

{% hint style="warning" %}
В Settings задаются общие параметры шага:

* **Title** — название шага
* **Delay** — задержка от предыдущего шага до отправки
* **Finish Status** — статус диалога после выполнения шага
* **Skip the transition to next step** — не переводит на следующий шаг автоматически
* **Hide keyboard** — скрывает клавиатуру у пользователя
* **Is start step of flow** — делает шаг стартовым

Если вы используете `waiting` и пуши, включите **Skip the transition to next step**. Тогда шаг останется активным и будет ждать ответ пользователя.

{% endhint %}

### Manual Messages:

{% hint style="info" %}
В этом блоке создаются основные сообщения шага.

Доступные типы сообщений:

* **Text** — готовый текст
* **Prompt** — текст по вашему запросу
* **Media** — фото, видео, скриншоты
* **Document** — файлы и документы
* **Video Note** — видеокружочки
* **Voice** — голосовые сообщения

Кнопки не создаются как отдельный тип сообщения.

**Inline Buttons** и **Keyboard** прикрепляются к нужному сообщению:

* **Inline Buttons** — кнопки внутри сообщения
* **Keyboard** — кнопки снизу в чате

Сообщения отправляются по очереди.

Можно комбинировать разные типы и собирать цепочку из нескольких сообщений.

**Pin message** закрепляет сообщение в диалоге.

<img src="../../../../.gitbook/assets/Frame 2248 (46).png" alt="" data-size="original">
{% endhint %}

### Push Messages:

{% hint style="info" %}
Push Messages — это дополнительные сообщения, которые отправляются, если пользователь молчит.

Доступны два варианта:

* **Global push messages** — используются глобальные пуши бота
* **Step push messages** — пуши настраиваются внутри текущего шага

Каждый следующий пуш отправляется после предыдущего.

Задержка задается вручную.

Если пользователь ответил, пуши останавливаются.
{% endhint %}

### Когда использовать Send Message:

{% hint style="warning" %}
* для первого контакта
* для отправки инструкции
* для отправки фиксированного текста
* для медиа, файлов, голосовых и видеокружков
* для цепочки сообщений с задержками
* для пушей и догрева
{% endhint %}
