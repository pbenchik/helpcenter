# Note

> ### Note - это шаг, который позволяет добавлять заметки внутри flow.

{% hint style="info" %}
**Позволяет оставлять визуальную заметку с текстом в воронке.**

<img src="../../../../.gitbook/assets/image (99).png" alt="Шаг Note" data-size="original">
{% endhint %}

### Основные возможности:

{% hint style="info" %}
**С помощью Note вы можете:**

* добавлять текстовые заметки в flow
* описывать назначение шагов
* оставлять комментарии для команды
* визуально структурировать сценарий
{% endhint %}

### Структура шага:

{% hint style="info" %}
**Note не имеет настроек как другие шаги.**\
**Это вспомогательный элемент внутри flow.**
{% endhint %}

### Как использовать:

{% hint style="info" %}
**При использовании Note вы можете:**

* вписать любой текст
* изменить размер блока
* выбрать цвет заметки
* перемещать её по рабочей области
{% endhint %}

### Важная логика работы:

{% hint style="warning" %}
**Note не влияет на выполнение сценария**\
Не участвует в логике переходов\ Не взаимодействует с пользователем\ Используется только для внутренней работы
{% endhint %}

### Когда использовать Note:

{% hint style="success" %}
**Используйте этот шаг, когда нужно:**

* оставить комментарий внутри flow
* описать логику сценария
* упростить работу с большим количеством шагов
* структурировать воронку
{% endhint %}
