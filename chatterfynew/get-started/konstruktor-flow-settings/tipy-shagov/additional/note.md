# Note

Note позволяет добавлять заметки внутри flow.

<img src="../../../../.gitbook/assets/image (99).png" alt="Шаг Note" data-size="original">

### How it works

Note — это вспомогательный элемент внутри flow.

* добавляет текстовые заметки
* помогает описывать назначение шагов
* позволяет оставлять комментарии для команды
* помогает визуально структурировать сценарий

Note не имеет настроек как другие шаги.

### Steps / Instructions

1. Добавьте шаг **Note** в рабочую область.
2. Впишите нужный текст.
3. При необходимости измените размер блока.
4. При необходимости выберите цвет заметки.
5. Переместите заметку в нужную часть flow.

### Notes

* Note не влияет на выполнение сценария
* Note не участвует в логике переходов
* Note не взаимодействует с пользователем
* Note используется только для внутренней работы
* Используйте шаг, когда нужно оставить комментарий внутри flow, описать логику сценария, упростить работу с большим количеством шагов или структурировать воронку
