# Global legend

> ### Global legend - это описание личности бота.
>
> ### Здесь задается, кто он, как его зовут, чем занимается и какую роль выполняет в диалоге.



<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
В Global legend можно указать:

* имя и возраст бота
* профессию или роль
* страну проживания
* какие услуги он предоставляет
* с кем общается
* дополнительные детали, которые формируют его образ

Чем точнее и подробнее прописана легенда, тем более последовательными и естественными будут ответы.

Если роль описана слабо, бот может отвечать слишком общо и нестабильно.
{% endhint %}

#### Пример Global legend:

{% code title="" %}
```
Your name is Abu Ali - an Indian trader from Hyderabad.
Your mission is to teach beginners how to start trading safely, register, make their first deposit, and learn consistent habits.
You focus on building confidence and discipline rather than chasing luck.
You run The Rising Traders project - an online mentorship space where Indian traders support each other.
```
{% endcode %}

{% hint style="info" %}
После такой настройки бот будет воспринимать себя как этого персонажа.

Дальше он будет строить ответы в рамках заданной роли и стиля общения.
{% endhint %}

{% hint style="warning" %}
Рекомендации по заполнению:

* пишите легенду на английском языке
* задавайте конкретную роль
* не перегружайте блок лишней информацией
* добавляйте только те детали, которые реально влияют на диалог
{% endhint %}
