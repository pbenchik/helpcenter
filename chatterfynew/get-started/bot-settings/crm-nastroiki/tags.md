# Tags

**Tags** — это инструмент для маркировки и сегментации диалогов.

### Что можно делать

С помощью тегов можно быстро выделять нужные группы лидов.

* быстро сегментировать диалоги
* визуально выделять нужные группы лидов
* назначать метки вручную и автоматически
* управлять внутренними сценариями обработки

### Как это работает

По своей логике **Tags** похожи на **Sale Status**.

Разница в том, что теги гибче и не привязаны к одному этапу продажи.

Их можно использовать для любых внутренних сегментов и сценариев.

#### Steps / Instructions

1. Откройте нужного бота и перейдите в **Bot Settings**.
2. Откройте вкладку **Tags**.
3. Нажмите **Add New Tag**.
4. Заполните настройки тега.
5. Укажите `Tag Name`, выберите цвет и сохраните изменения.

### Примеры тегов

Названия зависят от вашей сегментации.

* `VIP`
* `New lead`
* `Warm audience`

### Как назначить Tags

Тег можно назначить вручную или автоматически.

### How it works

* вручную — через CRM и карточку клиента
* автоматически — через шаг [Change tag](../../konstruktor-flow-settings/tipy-shagov/changes/change-tag.md)

### Где используются Tags

Теги применяются в CRM и в логике воронки.

### How it works

* в CRM и карточке клиента
* в логике воронки через шаг **Change tag**

Это помогает:

* сегментировать лидов
* упрощать навигацию по диалогам
* управлять внутренними сценариями обработки

### Важные особенности

Tags предназначены для внутренней работы и гибкой сегментации.

* один и тот же тег можно использовать в разных сценариях
* названия тегов лучше делать короткими и понятными
* цвет тега помогает быстрее находить нужные сегменты

### Где удобно использовать Tags

Этот инструмент полезен, когда нужно быстро маркировать диалоги.

* разделять лидов по типу или источнику
* помечать важные сегменты для команды
* запускать разную логику воронки
* быстро находить нужные диалоги в CRM
