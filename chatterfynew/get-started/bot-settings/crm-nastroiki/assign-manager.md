# Assign Manager

> ### Assign Manager - это инструмент для управления распределением чатов между операторами.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2251 (10).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
С его помощью можно:

\- разграничивать доступ к чатам

\- контролировать рабочую нагрузку операторов

\- распределять лидов внутри команды

\- управлять видимостью чатов в CRM
{% endhint %}

### Как работает Assign Manager:

{% hint style="info" %}
Assign Manager определяет, какие чаты оператор видит в CRM.
{% endhint %}

{% hint style="info" %}
Это помогает разделять зоны ответственности и упрощает работу команды с очередью диалогов.
{% endhint %}

### Как открыть Assign Manager:

{% stepper %}

### Подробнее:

<details>

<summary>Варианты отображения чатов</summary>

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2256 (7).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Доступны три режима:

* Show all chats - оператор видит все чаты, включая закреплённые за другими обработчиками
* Show only assigned chats - оператор видит только чаты, закреплённые за ним
* Show assigned + unassigned chats - оператор видит свои чаты и все чаты без назначенного обработчика
{% endhint %}

</details>

<details>

<summary>Как назначить менеджера</summary>

{% hint style="info" %}
Менеджера можно назначить тремя способами:

* вручную - через карточку клиента
* массово - через раздел [Users](../../crm/users/)
* автоматически - через шаг [Operator](../../konstruktor-flow-settings/tipy-shagov/changes/operator.md)
{% endhint %}

</details>

<details>

<summary>Важные особенности</summary>

{% hint style="warning" %}
**Assign Manager нужен для внутренней работы команды.**

* он помогает управлять очередью операторов
* он упрощает контроль закреплённых и свободных чатов
* он делает распределение лидов понятнее для команды
{% endhint %}

{% hint style="info" %}
Эта настройка влияет на прозрачность работы операторов и упрощает контроль диалогов в CRM.
{% endhint %}

</details>

### Где удобно использовать Assign Manager:

{% hint style="success" %}
Assign Manager удобно использовать, когда нужно:

* разделить чаты между операторами
* ограничить доступ к чужим диалогам
* показывать свободные чаты без назначенного менеджера
* автоматизировать закрепление лидов в воронке
{% endhint %}
