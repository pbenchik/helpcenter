# Assign Manager

**Assign Manager** — это инструмент для управления распределением чатов между операторами.

### Что можно делать

![](<../../../.gitbook/assets/Frame 2251 (10).png>)

С его помощью можно управлять видимостью чатов внутри команды.

* разграничивать доступ к чатам
* контролировать рабочую нагрузку операторов
* распределять лидов внутри команды
* управлять видимостью чатов в CRM

### Как это работает

Assign Manager определяет, какие чаты оператор видит в CRM.

Это помогает разделять зоны ответственности и упрощает работу команды с очередью диалогов.

### Как открыть Assign Manager

#### Steps / Instructions

1. Перейдите в **CRM-настройки**.
2. Откройте раздел **Assign Manager**.

### Варианты отображения чатов

![](<../../../.gitbook/assets/Frame 2256 (7).png>)

Доступны три режима отображения.

### How it works

* **Show all chats** — оператор видит все чаты, включая закреплённые за другими обработчиками
* **Show only assigned chats** — оператор видит только чаты, закреплённые за ним
* **Show assigned + unassigned chats** — оператор видит свои чаты и все чаты без назначенного обработчика

### Как назначить менеджера

Менеджера можно назначить вручную, массово или автоматически.

### How it works

* вручную — через карточку клиента
* массово — через раздел [Users](../../crm/users/)
* автоматически — через шаг [Operator](../../konstruktor-flow-settings/tipy-shagov/changes/operator.md)

### Назначение через карточку клиента

![](<../../../.gitbook/assets/Frame 2216.png>)

Этот вариант подходит, когда нужно вручную закрепить конкретного оператора за пользователем.

### Массовое назначение через Users

![](<../../../.gitbook/assets/Frame 2217.png>)

Этот вариант удобен, когда нужно быстро распределить сразу несколько пользователей.

### Автоматическое назначение через Operator

![](<../../../.gitbook/assets/image (29).png>)

Этот вариант используют в воронках, когда менеджер должен назначаться по логике сценария.

### Где используется Assign Manager

Настройка применяется в трёх основных сценариях.

* в карточке клиента
* в массовых действиях по пользователям
* в автоматизации через шаг **Operator**

### Важные особенности

Assign Manager нужен для внутренней работы команды.

* помогает управлять очередью операторов
* упрощает контроль закреплённых и свободных чатов
* делает распределение лидов понятнее для команды

### Где удобно использовать Assign Manager

Этот инструмент полезен, когда нужно навести порядок в распределении чатов.

* разделить чаты между операторами
* ограничить доступ к чужим диалогам
* показывать свободные чаты без назначенного менеджера
* автоматизировать закрепление лидов в воронке
