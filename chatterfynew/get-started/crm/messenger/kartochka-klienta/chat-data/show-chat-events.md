# Show chat events

> ### Функция Show Chat Events позволяет отображать или скрывать технические события внутри диалога.

{% hint style="info" %}
*

    <div data-with-frame="true"><figure><img src="../../../../../.gitbook/assets/Frame 2242.png" alt=""><figcaption></figcaption></figure></div>



Доступны следующие типы событий:

* Change Status - изменение статуса (например, с waiting на auto)
* Change Step - переходы между шагами
* Error - ошибки
* Change Tags - изменения тегов

AI - события, связанные с работой ИИ:

* Request AI Summary / Router
* Request AI Reply

Это полезно для анализа логики работы бота и отладки сценариев.
{% endhint %}
