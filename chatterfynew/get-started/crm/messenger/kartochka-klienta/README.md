# Карточка клиента

_Карточка клиента_ — основной рабочий интерфейс для взаимодействия с конкретным лидом.

В ней собраны инструменты для управления диалогом, изменения параметров пользователя и просмотра данных.

### Как это работает

Карточка клиента делится на три вкладки.

Каждая вкладка отвечает за свой тип данных и действий.
