# Events

_Events_ позволяет отслеживать действия пользователя в реальном времени.

Это помогает видеть поведение лида, оптимизировать воронку и эффективнее управлять диалогом.

### Как это работает

**Show events** включает и выключает отображение конкретных событий во вкладке **Events**.

### Типы событий

* **Page View** — пользователь просмотрел лендинг после перехода по ссылке из кампании
* **Click** — нажатие по кнопке на лендинге

{% hint style="info" %}
Если в настройках кампании включена функция **Auto redirect**, событие **Click** не фиксируется.
{% endhint %}

* **Subscribe** — подписка
  * При заливе на канал событие фиксируется в момент принятия заявки ботом-автоприёмщиком.
  * При заливе на бота событие фиксируется в момент, когда пользователь запускает бота.
* **Contact** — пользователь написал текст, отправил медиа или эмоджи, либо нажал кнопку типа **Keyboard**
* **Registration** — регистрация пользователя
* **FD / RD** — первый депозит и повторный депозит

### Как события могут фиксироваться

* вручную
* через шаг [Send event](send-event.md)
* автоматически через `Postback`
