# Inbox Control

> ### Inbox Control помогает быстро работать со списком чатов в Messenger.

Здесь можно переключаться между вкладками, фильтровать диалоги и сохранять нужные выборки.

### **Основные вкладки**:

{% hint style="info" %}
В верхней части раздела доступны основные вкладки для работы с чатами.

*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2220.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **All — список всех чатов в боте или личке**:

*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2174.png" alt=""><figcaption></figcaption></figure></div>

### **My Chats — чаты, которые назначены на вас**:

{% hint style="info" %}
* Вкладка **My Chats** используется, когда работа распределяется между менеджерами или обработчиками.
* Так проще видеть только свои диалоги и не отвлекаться на общий поток.
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2221.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **Favorites — избранные чаты для быстрого доступа**:

{% hint style="info" %}
Как добавить чат в **Favorites**:

1. Откройте нужный чат.
2. Нажмите на значок `⭐️` слева от аватарки.
3. После этого:

* чат появится во вкладке **Favorites**
* в общем списке у пользователя появится значок звезды на аватарке
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2222.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **Chat Status**:

{% hint style="info" %}
* Блок **Chat Status** нужен для быстрой фильтрации чатов по статусам.
* Он помогает сразу отделить новые, активные и завершённые диалоги.
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2137.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **3. Фильтрация**:

{% hint style="info" %}
* Фильтры помогают быстро находить нужные чаты по заданным параметрам.
* Это удобно для ежедневной работы с диалогами и сегментации лидов.
* Чтобы открыть фильтрацию, нажмите **Filters**.
* **Место для скриншота:** кнопка **Filters** над списком чатов.
{% endhint %}

***

### **Доступные параметры фильтрации**:

{% hint style="info" %}
* **Step** — шаг пользователя
* **Flow** — текущий флоу
* **Tags** — наличие или отсутствие тегов
* **Custom Fields** — значения кастомных полей
* **Tracker Fields** — значения трекерных полей
* **Assign** — назначенный менеджер
* **Status** — статус чата
* **Sale Stage** — этап продажи
* **Events** — события
* **Total Deposit** — сумма депозитов
* **Created At** — дата создания чата
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 1437256012.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **Default и Smart Filters**:

{% hint style="info" %}
* **Default Filters** — базовый набор фильтрации.
* Сюда входят основные параметры: **Flow**, **Tags**, **Step**, **Status**, **Assign** и дата создания чата.
* **Smart Filters** — расширенный режим фильтрации.
* Он даёт доступ ко всем доступным параметрам, включая кастомные поля, события, этапы продаж, депозиты и другие данные.
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 1437256012 (1).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **Custom Filters**:

{% hint style="info" %}
* **Custom Filters** — это общие фильтры внутри бота.
* Они доступны всем пользователям, у которых есть доступ к этому боту.
* Настройка выполняется в разделе **Bot Settings → Custom Filters**.
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 1437256012 (2).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **My Filters**:

{% hint style="info" %}
* **My Filters** — это личные фильтры пользователя.
* Они сохраняются отдельно для каждого сотрудника.
* Эти фильтры не видны другим пользователям.
* Их удобно использовать для часто повторяющихся выборок.
* Чтобы сохранить такой фильтр, настройте **Smart Filter** и нажмите **Save Filter**.
* После этого фильтр появится в разделе **My Filters**.
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 1437256012 (3).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}
