# Управление рассылками

> ### После создания рассылки её можно отслеживать во вкладке **Mailings**.
>
> ### Здесь отображается список рассылок, их статус и основные действия для управления.



***

### 1. Основные поля:

{% hint style="info" %}
В списке рассылок отображаются основные параметры каждой отправки:

* **Status** — статус рассылки, например `Completed`
* **Name** — название рассылки
* **Include** — типы контента в рассылке
* **Created by** — автор рассылки
* **Start** — время начала отправки
* **Created at** — дата создания
* **Progress** — прогресс отправки: сколько сообщений уже отправлено
* **Answer** — процент пользователей, которые ответили
{% endhint %}

***

### 2. Actions:

{% hint style="info" %}
Для каждой рассылки доступны действия управления.

*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2248 (48).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

{% hint style="info" %}
Основные действия:

* **Users** — просмотр списка пользователей и статуса отправки
* **Stats** — переход к аналитике рассылки
* **Duplicate** — создание копии рассылки
* **Archive** — архивирование рассылки
{% endhint %}

{% hint style="info" %}
В разделе **Users** можно посмотреть:

* Имя пользователя
* Username
* Время отправки
* Наличие ответа
* Кнопку перехода в чат
{% endhint %}

{% hint style="warning" %}
Действие **Archive** доступно для рассылок в статусе **Paused**.
{% endhint %}

***

### 3. Архивированные рассылки:

{% hint style="info" %}
Архивированные рассылки можно найти через фильтр:

**Filters → Status → Archived**
