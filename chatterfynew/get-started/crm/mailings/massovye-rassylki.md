# Массовые рассылки

Массовые рассылки позволяют отправлять сообщения выбранной базе пользователей.

Сообщения отправляются последовательно с учётом заданных настроек отправки.

### Видео

{% embed url="https://youtu.be/73wgcPJO3yg" %}

### Поддерживаемые форматы

* **Text** — текстовые сообщения
* **Media** — изображения и видео
* **Document** — документы
* **Video Note** — видео-кружки
* **Voice** — голосовые сообщения
* **Audio** — аудиофайлы

### Когда использовать

* для повторного контакта с базой
* для уведомлений по сегменту пользователей
* для отправки одного сообщения сразу нескольким получателям
