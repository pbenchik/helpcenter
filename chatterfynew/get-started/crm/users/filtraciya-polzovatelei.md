# Фильтрация пользователей

Фильтры помогают быстро находить нужных пользователей по заданным параметрам.

### Как это работает

Фильтры позволяют собрать нужный сегмент пользователей по данным CRM и Tracker.

Настроенные варианты можно сохранить в **My Filters** для регулярной работы.

### Как открыть фильтрацию

#### 1. Откройте фильтры

<img src="../../../.gitbook/assets/Frame 2206.png" alt="" data-size="original">

* Нажмите **Filters**.

#### 2. Настройте параметры

<img src="../../../.gitbook/assets/Frame 2205.png" alt="" data-size="original">

* Выберите нужные условия, чтобы отфильтровать пользователей.

### Доступные параметры

* **Step** — шаг пользователя
* **Flow** — текущий флоу
* **Tags** — [Tags](../../bot-settings/crm-nastroiki/tags.md)
* **Custom Fields** — [Custom Fields](../../bot-settings/custom-fields.md)
* **Tracker Field** — [Tracker Data](../messenger/kartochka-klienta/chat-data/tracker-data.md)
* **Assign** — [Assign Manager](../../bot-settings/crm-nastroiki/assign-manager.md)
* **Status** — [Chat status](../messenger/chat-status.md)
* **Sale Stage** — [Sale Status](../../bot-settings/sale-status.md)
* **Events** — [Events](../messenger/kartochka-klienta/events/)
* **Total Deposit** — сумма депозитов
* **Created At** — дата создания чата

### Notes

{% hint style="info" %}
В **Tracker Field** можно использовать кампанию, сорс, домен, лендинг, тип залива и тип сорса.

Эти поля доступны, если у пользователя есть доступ к Tracker.
{% endhint %}
