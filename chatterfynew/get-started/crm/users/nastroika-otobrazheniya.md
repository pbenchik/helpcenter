# Настройка отображения

С помощью **Columns** можно настроить отображение полей в таблице пользователей.

### Как это работает

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Comp-1_9 (1).gif" alt=""><figcaption></figcaption></figure></div>

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2248 (49).png" alt=""><figcaption></figcaption></figure></div>

Через **Columns** можно включать и скрывать нужные колонки.

### Что можно включить

* кастомные поля
* трекерные поля
* другие дополнительные колонки для работы
