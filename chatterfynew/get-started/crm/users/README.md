# Users

_Users_ — это список всех пользователей, которые написали в выбранного бота или личный аккаунт.

### Как это работает

<figure><img src="../../../.gitbook/assets/unknown (149).png" alt=""><figcaption></figcaption></figure>

В этом разделе можно просматривать, фильтровать и управлять диалогами.

Также здесь доступны массовые действия с чатами.

### Что можно делать

* просматривать список пользователей
* фильтровать диалоги
* менять отображение таблицы
* выполнять массовые действия
* создавать рассылки
