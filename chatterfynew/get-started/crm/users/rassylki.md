# Рассылки

> ### Рассылки — это отправка одного сообщения сразу нескольким клиентам.

{% hint style="info" %}
В разделе Users можно быстро создать рассылку по кнопке **Create Mailing**.

*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2203 (1).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

{% hint style="info" %}
После нажатия откроется форма создания рассылки.

В ней можно:

* задать название рассылки
* добавить сообщение
* настроить задержку отправки
* запланировать старт
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2204 (1).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

{% hint style="info" %}
Подробная инструкция доступна здесь: <a href="../mailings/" class="button secondary">Как создать и настроить рассылку</a>
{% endhint %}
