# Tracker

**Tracker** — это раздел аналитики по событиям и конверсиям из Tracker.

### Что можно делать

![](<../../.gitbook/assets/image (126).png>)

С его помощью можно анализировать путь пользователя до целевого действия.

* оценивать качество трафика
* анализировать конверсии на каждом этапе
* находить слабые места в воронке
* отслеживать путь пользователя до целевого действия

### Как это работает

В этом разделе собрана аналитика по пути пользователя от диалога до регистрации, первого депозита и повторных депозитов.

Это помогает понять, как пользователи проходят воронку и на каком этапе происходят основные потери.

### Steps / Instructions

1. Откройте вкладку **Tracker** в разделе **Analytics**.
2. Посмотрите основные метрики сверху.
3. Сравните графики по этапам воронки.
4. Выберите нужный период для анализа.

### Основные метрики

В разделе доступны ключевые показатели.

* **Dialogs** — количество диалогов
* **Dia To Reg** — конверсия из диалога в регистрацию
* **Registrations** — количество регистраций
* **Reg To FD** — конверсия из регистрации в первый депозит
* **Dia To FD** — конверсия из диалога в первый депозит
* **FD** — количество первых депозитов
* **FD To Uniq RD** — конверсия из первого депозита в уникальные повторные депозиты
* **Unique RD** — количество пользователей с повторными депозитами
* **FD To RD** — конверсия из первого депозита в повторные депозиты
* **RD** — количество повторных депозитов

### How it works

Эти метрики помогают быстро понять, как пользователи проходят путь от первого диалога до депозитов.

### Графики

![](<../../.gitbook/assets/Frame 2256 (15).png>)

Каждый показатель отображается на отдельном графике.

### How it works

Это позволяет:

* смотреть данные по дням
* отслеживать динамику изменений
* сравнивать поведение пользователей на разных этапах

### Выбор периода

![](<../../.gitbook/assets/image (125).png>)

Для каждого графика можно выбрать период.

### How it works

* `Today`
* `7 days`
* `14 days`
* `30 days`
* `90 days`

Также можно выбрать конкретные даты через календарь.

### Notes

* Выбранный период влияет на все показатели и графики.
* Перед анализом убедитесь, что выбран нужный диапазон дат.

### Важные особенности

Эти особенности важно учитывать при чтении метрик.

* метрики показывают путь пользователя по событиям Tracker
* просадка между этапами помогает находить слабые места в воронке
* для корректного анализа важно выбрать правильный период

### Где удобно использовать Tracker

Этот раздел полезен, когда нужно оценивать качество трафика и конверсии.

* проверить качество трафика
* оценить конверсии между этапами
* найти просадки между регистрацией и депозитом
* отследить эффективность воронки по событиям
