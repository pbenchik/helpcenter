# Integrations - подключение партнёрских программ

> ### Раздел Integrations используется для подключения партнёрских программ и настройки передачи событий в Tracker посредством постбеков. &#x20;

С помощью интеграций система получает информацию о действиях пользователей и фиксирует события внутри платформы.     &#x20;

{% hint style="warning" %}
Передаваемые события могут включать:



* регистрацию пользователя (registration)
* первый депозит (sale)
* повторный депозит (resale)
* вывод (withdraw)
* любые другие события, которые передаёт партнёрская программа, при их наличии и необходимости.

Эти данные используются для аналитики и оценки эффективности рекламного трафика.
{% endhint %}

***

### Где находится раздел Integrations:

{% hint style="info" %}
*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2190.png" alt=""><figcaption></figcaption></figure></div>

  * Перейдите в Tracker
  * Выберите раздел Integrations
* Здесь отображается список всех подключенных интеграций.
{% endhint %}
