# Integrations - подключение партнёрских программ

## Integrations - подключение партнёрских программ

Раздел **Integrations** используется для подключения партнёрских программ и настройки передачи событий в Tracker через постбеки. С его помощью система получает данные о действиях пользователей и фиксирует события внутри платформы.

### Как это работает

Партнёрская программа передаёт события в Tracker. Эти данные используются для аналитики и оценки эффективности рекламного трафика.

Передаваемые события могут включать:

* регистрацию пользователя — `registration`
* первый депозит — `sale`
* повторный депозит — `resale`
* вывод — `withdraw`
* любые другие события, которые передаёт партнёрская программа

### Где находится раздел Integrations

Раздел **Integrations** находится в **Tracker**. Здесь отображается список всех подключённых интеграций.

![Раздел Integrations](<../../../.gitbook/assets/Frame 2190.png>)

### Как открыть раздел

1. Перейдите в **Tracker**.
2. Выберите раздел **Integrations**.
3. Откройте список подключённых интеграций.
