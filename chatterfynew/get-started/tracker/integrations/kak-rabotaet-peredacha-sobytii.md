# Как работает передача событий

## Как работает передача событий

Процесс передачи событий состоит из нескольких этапов. Он связывает клик пользователя, регистрацию и события партнёрской программы.

### Как это работает

Система создаёт `clickid` при первом переходе пользователя по ссылке кампании. Дальше этот `clickid` передаётся в ссылке регистрации и возвращается в postback.

### Этапы передачи событий

1. Пользователь приходит из рекламы.
2. Пользователь нажимает на рекламное объявление и переходит по ссылке кампании.
3. В этот момент Chatterfy автоматически создаёт уникальный идентификатор `clickid`.
4. Во время общения в боте или личке пользователю отправляется ссылка на регистрацию.
5. В эту ссылку добавляется специальный макрос `{{tracker.clickid}}`.
6. Когда пользователь совершает действие, партнёрская программа отправляет postback в Chatterfy.
7. Chatterfy находит пользователя по `clickid`, определяет кампанию и записывает событие в систему.

### Пользователь приходит из рекламы

`clickid` — это уникальный ID клика пользователя. Он создаётся системой при первом переходе по ссылке и сохраняется вместе с данными пользователя.

### Пользователь получает ссылку на регистрацию

Во время общения пользователю отправляется ссылка на регистрацию. В неё добавляется макрос `{{tracker.clickid}}`.

Пример ссылки:

`https://partner.com/signup?sub1={{tracker.clickid}}`

Когда ссылка отправляется пользователю через CRM, система автоматически подставляет значение `clickid`.

Пример итоговой ссылки:

`https://partner.com/signup?sub1=67wgwWkaR0`

Так партнёрская программа получает `clickid`, который был создан при первом переходе пользователя.

### Партнёрская программа отправляет postback

Когда пользователь совершает действие, например регистрацию или депозит, партнёрская программа отправляет postback в Chatterfy.

Пример:

[https://api.chatterfy.ai/api/postbacks/.../tracker-postback?clickid=67wgwWkaR0\&tracker.event=registration](https://api.chatterfy.ai/api/postbacks/.../tracker-postback?clickid=67wgwWkaR0\&tracker.event=registration)

### Chatterfy записывает событие

Получив postback, Chatterfy:

* находит пользователя по `clickid`
* определяет, по какой кампании он пришёл
* записывает событие в систему

Например:

* `registration` — регистрация
* `sale` — первый депозит
* `resale` — повторный депозит

После этого данные отображаются в:

* Analytics
* Dashboards
* Logs
* карточке клиента в разделе **Events**
