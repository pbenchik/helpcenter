# Типы интеграций

> ### Типы интеграций - это раздел, где выбирается способ подключения партнёрской программы к Tracker.

{% hint style="info" %}
С его помощью можно:

* выбрать готовую или кастомную интеграцию
* настроить передачу postback-событий
* связать события партнёрской программы с пользователями
* передавать регистрации, депозиты и дополнительные данные
{% endhint %}

### Как работают типы интеграций:

{% hint style="info" %}
В разделе Integrations доступны два типа интеграций:

* готовые интеграции
* кастомные интеграции
{% endhint %}

{% hint style="info" %}
Выбор зависит от того, есть ли ваша партнёрская программа в списке готовых подключений.
{% endhint %}

### Как выбрать тип интеграции:

{% stepper %}
{% step %}
{% hint style="info" %}
**Проверьте, есть ли партнёрская программа в списке**

Если программа есть в списке, используйте готовую интеграцию.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Используйте готовую интеграцию, если настройки уже поддерживаются системой**

В этом случае postback-параметры и ссылки уже подготовлены.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Используйте кастомную интеграцию, если готового варианта нет**

Тогда параметры, события и postback-ссылки настраиваются вручную.
{% endhint %}
{% endstep %}
{% endstepper %}

### Полезная информация:

<details>

<summary>Готовые интеграции</summary>

{% hint style="info" %}
В готовых интеграциях часть настроек уже подготовлена системой.

Вам не нужно самостоятельно создавать postback-ссылки или подбирать параметры.
{% endhint %}

{% hint style="info" %}
В интеграции уже настроены:

* postback-параметры
* события, которые будут отслеживаться
* готовые postback-ссылки
{% endhint %}

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image (103).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Останется только:

* скопировать postback-ссылки из интеграции
* добавить их в настройках партнёрской программы
* проверить соответствие параметров
{% endhint %}

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2191.png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
После этого Chatterfy сможет автоматически получать события от партнёрской программы и связывать их с пользователями.
{% endhint %}

</details>

<details>

<summary>Что нужно для готовой интеграции</summary>

{% hint style="info" %}
Для подключения необходимо:

* выбрать партнёрскую программу в разделе Integrations
* активировать интеграцию
* настроить postback в самой партнёрской программе
* добавить регистрационную ссылку в разделе Registration Links
{% endhint %}

</details>

<details>

<summary>Кастомные интеграции</summary>

{% hint style="info" %}
Если партнёрской программы нет в списке готовых интеграций, можно создать кастомную интеграцию.
{% endhint %}

{% hint style="info" %}
В этом случае нужно вручную:

* указать событие, например `registration`, `sale`, `resale`
* настроить postback-ссылки
* указать параметр `clickid` для сопоставления пользователя
* при необходимости передавать дополнительные данные в кастомные поля
{% endhint %}

{% hint style="info" %}
Например, через `fields.<key>` можно передавать:

* ID игрока
* промокод
* любые другие данные, которые поддерживает партнёрская программа
{% endhint %}

</details>

<details>

<summary>Что важно в кастомной интеграции</summary>

{% hint style="warning" %}
Параметр `clickid` обязателен.

Именно он позволяет системе сопоставить событие с конкретным пользователем.
{% endhint %}

{% hint style="info" %}
Для корректной работы также необходимо:

* настроить postback в самой партнёрской программе
* добавить регистрационную ссылку в разделе Registration Links
{% endhint %}

</details>

### Где удобно использовать разные типы интеграций:

{% hint style="success" %}
Этот раздел удобно использовать, когда нужно:

* быстро подключить популярную партнёрскую программу
* настроить передачу событий без готового шаблона
* связать регистрации и депозиты с пользователями в Tracker
* передавать дополнительные данные в кастомные поля
{% endhint %}
