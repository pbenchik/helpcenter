# Как использовать Dashboards

Раздел _Dashboards_ нужен для быстрого контроля трафика, кампаний и конверсий.

Здесь можно быстро собрать нужный срез без ручного поиска по таблице.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2157 (1).png" alt=""><figcaption></figcaption></figure></div>

### Как это работает

Фильтры показывают статистику по выбранным параметрам трафика.

Так удобно проверять отдельную кампанию, байера, креатив или другой сегмент.

### Шаги

#### 1. Откройте **Filters**

В верхней части **Dashboards** нажмите **Filters**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2155.png" alt=""><figcaption></figcaption></figure></div>

#### 2. Выберите параметры фильтрации

В списке отметьте нужные параметры.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2156.png" alt=""><figcaption></figcaption></figure></div>

#### 3. Укажите значения

Введите значения, по которым нужна статистика.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2157.png" alt=""><figcaption></figcaption></figure></div>

#### 4. Нажмите **Search**

Показатели и графики обновятся автоматически.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2158.png" alt=""><figcaption></figcaption></figure></div>

### Какие параметры можно использовать

Фильтрация работает по параметрам из трекинговой ссылки.

Например:

* `adset_name`
* `buyer_name`
* `creative_id`

### Notes

{% hint style="info" %}
Для детального анализа в таблице используйте [Analytics](analytics/).
{% endhint %}

* **Dashboards** подходят для быстрого контроля результатов, объёма трафика и конверсий.
