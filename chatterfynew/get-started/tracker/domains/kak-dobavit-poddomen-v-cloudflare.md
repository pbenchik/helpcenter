# Как добавить поддомен в Cloudflare

Эта инструкция помогает создать отдельный адрес внутри уже подключённого домена.

Она подходит для поддоменов вида `offer.example.com`.

### Видео

{% embed url="https://youtu.be/bHK-fuIVYTU" %}

### Как это работает

Поддомен создаётся как отдельная DNS-запись внутри уже подключённого домена.

После настройки DNS и SSL его можно использовать в кампаниях и лендингах.

### Шаги

1. откройте нужный домен в **Cloudflare**
2. перейдите в **DNS → Records**
3. создайте запись:
   * **Type** — `CNAME`
   * **Name** — имя поддомена, например `offer`
   * **Target** — `nemo.chatterfy.ai`
4. проверьте SSL в `SSL/TLS → Overview` и убедитесь, что включён `Flexible`
5. добавьте поддомен в Chatterfy через **Tracker → Domains**
6. откройте адрес в браузере и проверьте `HTTPS`

### Поля

* **Type** — тип DNS-записи
* **Name** — имя поддомена без основного домена
* **Target** — адрес назначения для поддомена
* **Domain** — полный адрес поддомена в Chatterfy

### Notes

{% hint style="info" %}
Для поддомена не нужно заново подключать `nameservers`. Достаточно создать DNS-запись внутри уже добавленного домена.
{% endhint %}

* Перед началом проверьте, что основной домен уже добавлен в Cloudflare
* Если основной домен ещё не подключён, сначала выполните шаги из статьи [Как добавить домен в Cloudflare](kak-dobavit-domen-v-cloudflare.md)
