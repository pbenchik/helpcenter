# Custom

**Custom** — режим загрузки собственного лендинга в Tracker.

### Обзор

![](<../../../.gitbook/assets/image 32591.png>)

Этот режим нужен, если вы хотите использовать готовую страницу вместо стандартного шаблона.

Он подходит для кастомного дизайна, своей структуры и нестандартной логики страницы.

### Как это работает

* Сначала создаётся новый landing в `Tracker → Landings`.
* Затем в настройках лендинга выбирается режим **Custom**.
* После этого загружается готовый `.zip`-архив.
* Сохранённый лендинг можно использовать в Campaigns.

### Шаги

#### 1. Создайте landing

* Создайте новый лендинг в `Tracker → Landings`.
* Откройте его карточку для дальнейшей настройки.

#### 2. Выберите режим **Custom**

* Переключите лендинг в режим **Custom**.
* Это переведёт страницу из шаблонного режима в режим загрузки архива.

#### 3. Загрузите архив

* Подготовьте и загрузите `.zip`-архив с готовым лендингом.
* Tracker использует содержимое архива как основу страницы.

#### 4. Подключите лендинг к кампании

* Сохраните настройки.
* Выберите лендинг в Campaigns.

### Требования к архиву

Архив должен быть полностью готов до загрузки в Tracker.

* Формат архива — `.zip`.
* В корне архива должен лежать `index.html`.
* Все стили должны быть внутри архива.
* Все изображения должны быть внутри архива.
* Все скрипты должны быть внутри архива.

### Как работает переход

* Элемент перехода должен содержать атрибут `tracker`.
* Таких элементов на странице может быть несколько.
* Все клики по ним фиксируются системой как переходы внутри лендинга.

### Notes

* Tracker не собирает страницу за вас.
* Система использует уже готовый архив как кастомный лендинг.
* Страницу нужно полностью подготовить заранее.

{% hint style="warning" %}
Не добавляйте в элемент с атрибутом `tracker` прямую ссылку и поле `href`.
{% endhint %}

Переход в Telegram Tracker формирует автоматически.

### Краткая логика

Создайте landing, выберите **Custom**, загрузите `.zip` и используйте лендинг в Campaigns.
