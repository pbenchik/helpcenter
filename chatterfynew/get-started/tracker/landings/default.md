# Default

**Default** — стандартный режим создания Telegram-лендинга в Tracker.

### Обзор

![](<../../../.gitbook/assets/image 32592.png>)

Этот режим подходит, если собственный архив не нужен.

Лендинг настраивается внутри системы и после сохранения может использоваться в кампании.

### Как это работает

* Вы заполняете базовые параметры лендинга.
* Затем настраиваете внешний вид страницы.
* При необходимости добавляете дополнительный код.
* После сохранения лендинг можно выбрать в Campaigns.

### Шаги

#### 1. Заполните **General**

* Укажите базовые параметры лендинга.
* Здесь задаются внутреннее имя и список байеров, которым доступен лендинг.

#### 2. Настройте **Settings**

* Заполните тексты, изображения, кнопки и другие визуальные элементы.
* На этом этапе формируется внешний вид страницы.

#### 3. При необходимости используйте **Custom code**

* Добавьте дополнительные стили и логику.
* Используйте этот блок, если стандартных настроек недостаточно.

#### 4. Подключите лендинг к кампании

* Сохраните лендинг.
* Выберите его в Campaigns.

### General

![](<../../../.gitbook/assets/image 32592.png>)

Раздел нужен для базовой настройки лендинга.

* `Name` — внутреннее название лендинга.
* `Buyers` — байеры, которым доступен лендинг.

### Settings

![](<../../../.gitbook/assets/unknown (92).png>)

Раздел нужен для настройки внешнего вида стандартного лендинга.

* `Description` — описание в верхней части страницы.
* `Title` — основной заголовок.
* `Avatar` — изображение в превью.
* `Text` — дополнительный текст.
* `Count` — количество участников или подписчиков.
* `Header button` — текст верхней кнопки.
* `Button text` — текст основной кнопки.

### Custom code

![](<../../../.gitbook/assets/unknown (90).png>)

Раздел нужен для дополнительной настройки лендинга.

* Меняйте стили страницы.
* Добавляйте кастомную вёрстку.
* Подключайте аналитику.
* Обрабатывайте действия пользователя.

### Notes

{% hint style="warning" %}
Если используется источник Facebook, invite-ссылки создаются системой автоматически.
{% endhint %}

* Вручную добавлять invite-ссылки в лендинг не требуется.
* Если invite-ссылка Telegram добавляется вручную, сначала настройте источник в разделе Sources и укажите эту ссылку там.
* Используйте [Custom](custom.md), если нужен кастомный дизайн, своя структура и нестандартная логика страницы.

### Когда использовать

* Чтобы быстро собрать лендинг без загрузки архива.
* Чтобы использовать стандартный шаблон Tracker.
* Чтобы запустить страницу с базовыми настройками и кнопками.
* Чтобы подключить лендинг к Campaigns без долгой подготовки.
