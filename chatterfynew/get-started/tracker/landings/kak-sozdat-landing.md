# Как создать landing

Создание landing — первый шаг перед настройкой страницы и подключением её к кампании.

### Видео

{% embed url="https://youtu.be/OI-rSu0Vw8o" %}

* Таймкоды: `00:08` — как найти раздел Landings, `00:16` — настройка landing.

### Как это работает

![](<../../../.gitbook/assets/Frame 2167.png>)

Новый лендинг создаётся в разделе `Tracker → Landings`.

После создания откройте его карточку и выберите тип:

* `Default` — стандартный шаблон.
* `Custom` — собственный архив.

После настройки лендинг можно использовать в Campaigns.

### Шаги

#### 1. Откройте **Landings**

![](<../../../.gitbook/assets/Frame 2167.png>)

* Перейдите в `Tracker → Landings`.
* В этом разделе хранится список всех лендингов Tracker.

#### 2. Нажмите **Create landing**

![](<../../../.gitbook/assets/image 32632.png>)

* Нажмите `Create landing`.
* Откроется окно создания нового лендинга.

#### 3. Откройте новый landing

* После создания откройте карточку лендинга.
* Дальше можно перейти к его детальной настройке.

#### 4. Выберите тип landing

* Выберите `Default`, если нужен стандартный шаблон.
* Выберите `Custom`, если нужен собственный архив.

### Notes

#### Перед началом

* Проверьте доступ к разделу `Tracker`.
* Заранее определите нужный тип: `Default` или `Custom`.
* Убедитесь, что лендинг нужен для конкретной кампании.

#### Что важно понимать

* `Landing` — отдельная страница внутри Tracker.
* Она служит точкой входа пользователя перед следующим шагом сценария.
* `Default` подходит для быстрой сборки страницы из готовых полей.
* `Custom` подходит для готовой страницы со своей структурой и дизайном.

#### Что проверить после создания

* Лендинг появился в разделе `Tracker → Landings`.
* Карточка лендинга открывается без ошибок.
* Понятно, какой тип нужно настраивать дальше.
* Лендинг готов к следующему этапу настройки.

### Когда использовать

* Чтобы быстро создать новый лендинг в Tracker.
* Чтобы подготовить лендинг под новую кампанию.
* Чтобы выбрать следующий шаг между `Default` и `Custom`.
