# Как создать landing

> ### Создать landing - это первый шаг перед настройкой страницы и подключением её к кампании.

### Видеоинструкция: Как создать landing:

{% hint style="info" %}
{% embed url="https://youtu.be/OI-rSu0Vw8o" %}

Таймкоды: 00:08 - Как найти раздел Landings, 00:16 - Настройка Landing
{% endhint %}

{% hint style="info" %}
С его помощью можно:

* создать новый лендинг в Tracker
* подготовить точку входа пользователя перед Telegram
* выбрать подходящий тип лендинга
* подготовить лендинг к использованию в Campaigns

    ![](<../../../.gitbook/assets/Frame 2167.png>)

### Как работает создание landing:

{% hint style="info" %}
Новый лендинг создаётся в разделе `Tracker → Landings`.
{% endhint %}

{% hint style="info" %}
После этого можно выбрать тип лендинга и заполнить его параметры.
{% endhint %}

### Как создать landing:

{% stepper %}
{% step %}
{% hint style="info" %}
* **Откройте раздел Landings**
* Перейдите в `Tracker → Landings`.
* Здесь хранится список всех лендингов внутри Tracker.
*   Скриншот:

    ![](<../../../.gitbook/assets/Frame 2167.png>)
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* **Нажмите Create landing**
* Нажмите кнопку `Create landing`.
* После этого откроется окно создания нового лендинга.
*   Скриншот:

    ![](<../../../.gitbook/assets/image 32632.png>)
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* **Откройте новый лендинг**
* После создания откройте карточку нового лендинга.
* Дальше можно перейти к детальной настройке страницы.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* **Выберите тип лендинга**
* После создания определите, какой тип лендинга будете настраивать:
* `Default` — если нужен стандартный шаблон
* `Custom` — если нужен собственный архив
{% endhint %}
{% endstep %}
{% endstepper %}

### Подробнее:

<details>

<summary>Что проверить перед созданием</summary>

{% hint style="info" icon="exclamation" %}
Перед созданием лендинга проверьте:

* у вас есть доступ к разделу `Tracker`
* вы уже понимаете, какой тип лендинга нужен: `Default` или `Custom`
* лендинг будет использоваться в нужной кампании
{% endhint %}

</details>

<details>

<summary>Какую роль создание landing играет в системе</summary>

{% hint style="warning" %}
Сначала в Tracker создаётся новый landing.

На этом этапе система добавляет отдельную страницу в список лендингов.
{% endhint %}

{% hint style="warning" %}
После создания становится доступна его внутренняя настройка.

Именно там дальше выбирается тип и заполняются параметры страницы.
{% endhint %}

{% hint style="warning" %}
После настройки лендинг можно использовать внутри Campaigns.

Так он становится частью маршрута пользователя до Telegram.
{% endhint %}

</details>

<details>

<summary>Что важно понимать перед настройкой</summary>

{% hint style="info" %}
`Landing` — отдельная страница внутри Tracker, которую можно использовать в кампании.

Она нужна как точка входа пользователя перед переходом дальше по сценарию.
{% endhint %}

{% hint style="info" %}
`Default` — стандартный тип лендинга.

Подходит, если вы хотите быстро собрать страницу из готовых полей.
{% endhint %}

{% hint style="info" %}
`Custom` — загрузка собственного архива с лендингом.

Подходит, если у вас уже есть готовая страница со своей структурой и дизайном.
{% endhint %}

</details>

<details>

<summary>Что проверить после создания</summary>

{% hint style="info" %}
После создания проверьте:

* лендинг появился в разделе `Tracker → Landings`
* карточка лендинга открывается без ошибок
* вы понимаете, какой тип нужен дальше: `Default` или `Custom`
* лендинг готов к следующему этапу настройки
{% endhint %}

</details>

### Где удобно использовать эту инструкцию:

{% hint style="success" %}
Эта инструкция удобна, когда нужно:

* быстро создать новый лендинг в Tracker
* подготовить лендинг под новую кампанию
* понять, какой тип лендинга настраивать дальше
* не пропустить базовый этап перед `Default` или `Custom`
{% endhint %}
