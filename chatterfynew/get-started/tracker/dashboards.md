# Dashboards

Раздел _Dashboards_ показывает сводную аналитику по трафику и кампаниям.

Он нужен для быстрого контроля без перехода в детальные таблицы.

### Как это работает

В верхней части отображаются ключевые метрики.

Ниже идут графики по этапам воронки и выбранным фильтрам.

### Как читать Dashboards

Этот раздел помогает быстро оценить состояние трафика.

#### Шаги

1. Смотрите ключевые метрики в верхней части
2. Проверяйте графики по этапам воронки
3. Применяйте фильтры для нужной связки, кампании или параметра

### Основные показатели

* **Clicks** — клики по кнопке перехода в Telegram
* **Subscribers** — подписки на канал или запуск бота
* **Dialogues** — пользователи с событием `contact`
* **Registration** — успешные регистрации
* **FD** — первые депозиты
* **RD** — повторные депозиты

### Графики

Dashboards показывает:

* **Page Views** — открытия лендинга
* **CTR** — соотношение просмотров и кликов
* **Views → Sub** — конверсия из просмотра в подписку
* **Clicks → Sub** — конверсия из клика в подписку
* **Subscribes / Unsubscribes / Net Subscribes** — динамика подписок
* **Net Clicks → Sub** — конверсия по уникальным кликам
* **Sub → Dia / Dialogues** — переход из подписки в диалог
* **Dia → Reg / Registrations** — переход из диалога в регистрацию
* **Reg → FD / FD** — переход из регистрации в первый депозит
* **Dia → FD** — переход из диалога в первый депозит
* **FD → Uniq RD / Unique RD** — переход к уникальным повторным депозитам
* **FD → RD / RD** — переход к повторным депозитам

{% hint style="info" %}
Используйте фильтры, если нужен срез по отдельной связке, кампании или параметру.
{% endhint %}
