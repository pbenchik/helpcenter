# Tracker

Раздел _Tracker_ нужен для отслеживания трафика, событий и конверсий.

Здесь вы настраиваете кампании, домены, лендинги, интеграции и аналитику.

### Как это работает

_Tracker_ показывает путь пользователя от клика до депозита.

#### Шаги

Основная логика такая:

1. подключаете домен
2. создаёте лендинг
3. настраиваете кампанию
4. запускаете трафик
5. проверяете события и аналитику

{% hint style="info" %}
Базовая цепочка: `домен → лендинг → кампания → источник → событие → аналитика`.
{% endhint %}
