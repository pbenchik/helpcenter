# Как использовать Dashboards

> ### Dashboards - это раздел для быстрого контроля трафика, кампаний и конверсий.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2157 (1).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
С его помощью можно:

\- смотреть статистику по выбранным параметрам трафика

\- анализировать отдельные кампании

\- быстро находить нужные сегменты данных

\- сравнивать результаты по фильтрам
{% endhint %}

### Как работают фильтры в Dashboards:

{% hint style="info" %}
Фильтры показывают статистику по выбранным параметрам трафика.
{% endhint %}

{% hint style="info" %}
Это удобно, когда нужно быстро посмотреть отдельную кампанию, баера, креатив или другой сегмент без ручного поиска.
{% endhint %}

### Как использовать фильтры:

{% stepper %}
{% step %}
{% hint style="info" %}
*   #### **Откройте Filters**

    В верхней части Dashboards нажмите **Filters**.

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2155.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Выберите параметры фильтрации**

    В выпадающем списке отметьте нужные параметры.

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2156.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Укажите значения фильтров**

    Введите значения, по которым нужна статистика.

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2157.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Нажмите Search**

    Показатели и графики обновятся автоматически.

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2158.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}
{% endstep %}
{% endstepper %}

* `adset_name`
* `buyer_name`
* `creative_id`

* объёма трафика
* конверсий

### Где удобно использовать Dashboards:

{% hint style="success" %}
Dashboards удобно использовать, когда нужно:

* быстро оценить результаты кампаний
* проверить трафик по отдельным параметрам
* отследить конверсии по нужному сегменту
* получить быстрый срез данных без таблиц
{% endhint %}
