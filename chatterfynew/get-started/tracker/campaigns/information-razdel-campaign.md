# Information- раздел campaign

> ### Information - это раздел Campaigns для базовой настройки кампании.

<div align="left" data-with-frame="true"><img src="../../../.gitbook/assets/image 32576.png" alt=""></div>

{% hint style="info" %}
С его помощью можно:

\- задать базовую структуру кампании

\- указать название и описание запуска

\- выбрать домен и лендинг

\- привязать кампанию к buyer
{% endhint %}

### Видеоинструкция:

{% hint style="info" icon="circle-user-circle-question" %}
В видео показано, как заполнить базовые поля кампании в разделе Information.

Подойдёт, если хотите быстро понять логику полей `Name`, `Description`, `Domain`, `Landing` и `Buyer`.

{% embed url="https://youtu.be/0RY4ENFSqas" fullWidth="false" %}
{% endhint %}

### Как работает Information:

{% hint style="info" %}
Здесь задаются ключевые параметры запуска до детальной настройки источников и фильтров.
{% endhint %}

{% hint style="info" %}
Если вы только начинаете настройку кампании, сначала заполните раздел Information.
{% endhint %}

### Как заполнить Information:

{% stepper %}
{% step %}
{% hint style="info" %}
#### **Задайте основу кампании**

Сначала в Information задаются базовые параметры кампании.

Это нужно, чтобы система понимала, какой запуск вы создаёте.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
#### **Выберите домен и лендинг**

Затем выбираются домен и лендинг.

Так задаётся путь пользователя после перехода по ссылке.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
#### **Подготовьте кампанию к следующим этапам**

После этого кампания переходит к следующим этапам настройки.

Дальше уже задаются источники, параметры, фильтры и тестирование.
{% endhint %}
{% endstep %}
{% endstepper %}

### Подробнее:

<details>

<summary>Что настраивается в Information</summary>

{% hint style="info" %}
В этом разделе обычно задают:

* название кампании
* краткое описание запуска
* домен для трекинговой ссылки
* лендинг для перехода пользователя
* buyer, к которому относится запуск
{% endhint %}

</details>

<details>

<summary>Какие поля есть в Information</summary>

{% hint style="info" %}
Основные поля:

* `Name` — название кампании
* `Description` — короткое описание запуска
* `Domain` — домен для генерации трекинговых ссылок
* `Landing` — лендинг, на который попадёт пользователь
* `Buyer` — buyer, к которому относится кампания
{% endhint %}

{% hint style="info" %}
Для `Name` удобно использовать формат:

* `Source | GEO | Offer | Date`
{% endhint %}

{% hint style="info" %}
Все значения можно изменить позже в режиме редактирования кампании.
{% endhint %}

</details>

### Где удобно использовать Information:

{% hint style="success" %}
Information удобно использовать, когда нужно:

* быстро задать основу новой кампании
* выбрать домен и лендинг до настройки источников
* привязать запуск к buyer
* подготовить кампанию к следующим этапам настройки
{% endhint %}
