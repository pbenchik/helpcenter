# Information- раздел campaign

Раздел _Information_ нужен для базовой настройки кампании.

Здесь задаются основные поля до детальной настройки источников и фильтров.

### Как это работает

Вкладка **Information** задаёт основу кампании.

Здесь выбираются название, описание, домен, лендинг и buyer.

### Шаги

1. задайте базовые параметры кампании
2. выберите домен и лендинг
3. привяжите кампанию к buyer
4. перейдите к следующим вкладкам настройки

### Поля

* **Name** — название кампании
* **Description** — короткое описание запуска
* **Domain** — домен для трекинговой ссылки
* **Landing** — лендинг, на который попадает пользователь
* **Buyer** — buyer, к которому относится кампания

### Notes

{% hint style="info" %}
Для поля `Name` удобно использовать формат `Source | GEO | Offer | Date`.
{% endhint %}
