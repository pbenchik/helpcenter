# Parameters- раздел campaing

Раздел _Parameters_ нужен для настройки параметров трекинговой ссылки.

Здесь вы определяете, какие значения будут передаваться вместе с переходом.

### Как это работает

Параметры помогают сохранять служебные метки для аналитики и CRM.

Часть параметров можно показывать в карточке лида.

### Шаги

#### 1. Откройте вкладку **Parameters**

#### 2. Добавьте новый параметр

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2164.png" alt=""><figcaption></figcaption></figure></div>

#### 3. Заполните основные поля

Укажите:

* `Name`
* `Parameter`
* `Placeholder`
* `Visible`

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2164 (1).png" alt=""><figcaption></figcaption></figure></div>

#### 4. Проверьте формат

Техническое имя должно быть без пробелов и кириллицы.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image (86).png" alt=""><figcaption></figcaption></figure></div>

#### 5. Нажмите **Save**

После сохранения параметр начнёт использоваться в ссылке кампании.

### Поля

* **Name** — понятное название параметра в интерфейсе
* **Parameter** — техническое имя параметра в ссылке
* **Placeholder** — значение, макрос или переменная для подстановки
* **Visible** — отображение параметра в CRM

### Частые параметры

* `buyer`
* `campaign`
* `creative`
* `sub1`
* `sub2`
* `clickid`

### Notes

{% hint style="warning" %}
Не используйте пробелы, кириллицу и случайные символы в `Parameter`.
{% endhint %}

* После сохранения проверьте ссылку, формат макросов и видимость полей в CRM
