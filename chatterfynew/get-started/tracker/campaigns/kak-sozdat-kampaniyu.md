# Как создать кампанию

Эта инструкция помогает создать новую кампанию в _Tracker_.

После сохранения кампания появляется в общем списке и готова к запуску.

### Как это работает

Кампания создаётся в разделе **Tracker → Campaigns**.

Во время создания нужно пройти все обязательные вкладки настройки.

### Шаги

#### 1. Откройте список **Campaigns**

Перейдите в `Tracker → Campaigns`.

![Список Campaigns](<../../../.gitbook/assets/Frame 2104.png>)

#### 2. Нажмите **Create campaign**

Нажмите `Create campaign` в правом верхнем углу.

![Кнопка Create campaign](<../../../.gitbook/assets/Frame 2105.png>)

#### 3. Заполните разделы кампании

Во время создания нужно пройти:

* [Information](information-razdel-campaign.md)
* [General](general-razdel-campaign.md)
* [Sources](sources-razdel-campaign/)
* [Auto actions](auto-actions-razdel-campaing.md)
* [Parameters](parameters-razdel-campaing.md)
* [Filters](filters-razdel-campaing.md)
* [Test](test-razdel-campaign.md)

#### 4. Сохраните кампанию

После сохранения:

* кампания появится в списке
* станет доступна ссылка запуска
* статистика начнёт собираться после старта трафика

### Notes

{% hint style="warning" %}
Перед запуском проверьте, что обязательные разделы заполнены и пройден раздел **Test**.
{% endhint %}
