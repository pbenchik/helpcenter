# Filters- раздел campaing

Раздел _Filters_ нужен для ограничения доступа к лендингу по условиям.

Здесь можно отсеивать нецелевой трафик по GEO, устройствам и ОС.

### Как это работает

Если пользователь проходит условия, он попадает на лендинг.

Если не проходит, система выполняет редирект.

### Шаги

1. откройте вкладку `Filters`
2. выберите разрешённые страны
3. задайте устройства и операционные системы
4. укажите действие и `URL` для редиректа
5. нажмите **Save**

### Поля

* **Available countries** — список стран с доступом к лендингу
* **Available device** — тип устройства: `Mobile`, `Tablet`, `Desktop`
* **Available OS** — операционная система: `iOS`, `Android`, `MacOS`, `Windows`
* **Redirect** — действие для нецелевого трафика
* **URL** — ссылка для редиректа

### Notes

{% hint style="warning" %}
Проверьте `URL` редиректа до запуска кампании. Нерабочая ссылка приведёт к ошибке вместо перенаправления.
{% endhint %}

* Раздел нужен, если вы хотите ограничить доступ по GEO, устройствам или ОС и уводить нецелевой трафик на отдельную страницу
