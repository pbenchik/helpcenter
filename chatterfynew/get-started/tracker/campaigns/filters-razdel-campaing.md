# Filters- раздел campaing

> ### Filters - это раздел Campaigns для ограничения доступа к лендингу по заданным условиям.

{% hint style="info" %}
С его помощью можно:

* показывать лендинг только целевой аудитории
* ограничивать доступ по GEO, устройствам и ОС
* отсекать невалидный трафик
* перенаправлять нецелевые переходы на отдельную страницу
{% endhint %}

### Как работает Filters:

{% hint style="info" %}
Фильтры особенно полезны, если вы разделяете трафик по GEO, устройствам или операционным системам.
{% endhint %}

{% hint style="info" %}
Если пользователь проходит условия, он попадает на лендинг.

Если не проходит, система выполняет заданный редирект.
{% endhint %}

### Как настроить Filters:

{% stepper %}
{% step %}
{% hint style="info" %}
**Откройте вкладку Filters**

Перейдите в нужную кампанию и откройте раздел `Filters`.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Выберите разрешённые страны**

Укажите GEO, которым должен быть доступен лендинг.

Это поможет отсечь нецелевой трафик по странам.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Выберите устройства и ОС**

Укажите, с каких устройств и операционных систем пользователи могут попасть на лендинг.

Это полезно, если связка рассчитана только на часть трафика.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Настройте редирект**

Выберите действие для пользователей, которые не прошли фильтр.

После этого укажите `URL`, куда система будет их перенаправлять.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Сохраните изменения**

Нажмите `Save`.

После сохранения фильтры начнут применяться ко всем новым переходам.
{% endhint %}
{% endstep %}
{% endstepper %}

* ограничить доступ к лендингу по GEO
* отсечь трафик с неподходящих устройств
* пускать пользователей только с нужной ОС
* перенаправлять нецелевой трафик на отдельную страницу
* защитить кампанию от нерелевантных переходов

<summary>Что проверить перед настройкой</summary>

{% hint style="info" icon="exclamation" %}
Перед настройкой Filters проверьте:

* вы понимаете, какой трафик считается целевым
* у вас есть рабочая ссылка для редиректа
* ограничения не конфликтуют с условиями запуска
{% endhint %}

<details>

<summary>Какую роль Filters играет в системе</summary>

{% hint style="warning" %}
Сначала пользователь открывает трекинговую ссылку кампании.

В этот момент Tracker получает базовые данные о переходе.
{% endhint %}

{% hint style="warning" %}
Дальше Tracker сравнивает страну, устройство и ОС пользователя с заданными условиями.

Так система определяет, является ли трафик целевым.
{% endhint %}

{% hint style="warning" %}
Если пользователь проходит фильтр, он попадает на лендинг.

Если не проходит, система выполняет редирект по заданному правилу.
{% endhint %}

</details>

<details>

<summary>Какие поля есть в Filters</summary>

{% hint style="info" %}
`Available countries` — список стран, которым разрешён доступ к лендингу.

Если страна пользователя не входит в список, трафик считается нецелевым.
{% endhint %}

{% hint style="info" %}
`Available device` — фильтр по типу устройства.

Можно ограничить показ лендинга по типам `Mobile`, `Tablet` и `Desktop`.
{% endhint %}

{% hint style="info" %}
`Available OS` — фильтр по операционной системе.

Можно выбрать нужные платформы, например `iOS`, `Android`, `MacOS` и `Windows`.
{% endhint %}

{% hint style="info" %}
`Redirect` — действие для пользователей, которые не прошли фильтр.

Обычно здесь выбирают перенаправление на безопасную или нейтральную страницу.
{% endhint %}

{% hint style="info" %}
`URL` — ссылка, на которую будет перенаправлён пользователь.

Обычно используется white page, нейтральный сайт или информационная страница.
{% endhint %}

</details>

<details>

<summary>Что проверить после настройки</summary>

{% hint style="warning" %}
Проверьте URL редиректа до запуска кампании.

Если ссылка не работает, пользователь увидит ошибку вместо перенаправления.
{% endhint %}

{% hint style="info" %}
После сохранения проверьте:

* целевой GEO проходит на лендинг
* нецелевой GEO уходит на редирект
* фильтр по устройствам работает корректно
* фильтр по ОС не режет нужный трафик
* URL редиректа открывается без ошибок
{% endhint %}

</details>

### Где удобно использовать Filters:

{% hint style="success" %}
Filters удобно использовать, когда нужно:

* защитить лендинг от нерелевантного трафика
* показывать связку только нужному GEO
* ограничить доступ по типу устройства или ОС
* уводить нецелевой трафик на безопасную страницу
{% endhint %}
