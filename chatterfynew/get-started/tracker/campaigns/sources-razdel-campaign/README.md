# Sources - раздел campaign

Раздел _Sources_ нужен для подключения и настройки источников трафика.

Здесь создаётся рабочая ссылка для запуска рекламы и передачи событий.

### Видео

{% embed url="https://youtu.be/DvlCSUyDOdM" fullWidth="false" %}

### Как это работает

Во вкладке **Sources** вы указываете, откуда приходит трафик.

От поля `Provider` зависит набор полей и логика передачи событий.

### Шаги

#### 1. Откройте раздел **Sources**

Перейдите в нужную кампанию и откройте вкладку `Sources`.

<figure><img src="../../../../.gitbook/assets/image (70).png" alt=""><figcaption></figcaption></figure>

#### 2. Нажмите **Add source**

После этого откроется форма создания источника.

<figure><img src="../../../../.gitbook/assets/Group 1437255925.png" alt=""><figcaption></figcaption></figure>

#### 3. Заполните базовые поля

Укажите `Name` и `Provider`.

<div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/image (71).png" alt=""><figcaption></figcaption></figure></div>

#### 4. Заполните параметры источника

Набор полей зависит от выбранного провайдера.

#### 5. Нажмите **Save**

После сохранения система сгенерирует рабочую ссылку.

### Поля

* **Name** — название источника внутри кампании
* **Provider** — тип источника трафика
* поля источника — параметры выбранного провайдера
* **Tracking link** — ссылка, которая создаётся после сохранения

### Notes

{% hint style="warning" %}
После сохранения источника создаётся отдельная рабочая ссылка. Одна кампания может использовать несколько источников.
{% endhint %}
