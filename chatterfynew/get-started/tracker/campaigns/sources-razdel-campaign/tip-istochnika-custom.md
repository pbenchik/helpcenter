# Тип источника Custom

Источник _Custom_ нужен для тестов, нестандартных сценариев и стороннего трафика.

Он подходит, когда нет готовой интеграции с рекламной платформой.

<div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/image 32588.png" alt="Настройка источника Custom"><figcaption></figcaption></figure></div>

### Как это работает

Источник `Custom` позволяет использовать свои параметры и свою логику запуска.

Через него удобно проверять ссылку, редиректы и общую маршрутизацию.

### Шаги

1. создайте кампанию
2. выберите тип источника `Custom`
3. проверьте передачу параметров
4. при необходимости включите `Auto redirect`

### Когда использовать

* для тестового трафика
* для стороннего источника
* для ручных сценариев
* для работы без готового шаблона интеграции

### Notes

{% hint style="warning" %}
Если источник трафика не подходит под готовые типы, используйте `Custom`.
{% endhint %}

* Источник не привязан к конкретной рекламной системе и подходит для нестандартной логики
