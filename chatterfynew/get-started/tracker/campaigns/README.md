# Campaigns

Раздел _Campaigns_ нужен для создания и управления рекламными кампаниями.

Здесь задаётся путь пользователя от клика до приёмщика лида.

<div align="left" data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2104.png" alt=""><figcaption></figcaption></figure></div>

### Как это работает

В кампании связываются домен, лендинг, источник трафика и маршрут пользователя.

После запуска кампания начинает собирать события и метрики.

### Как использовать

1. создайте новую кампанию
2. настройте маршрут трафика
3. запустите кампанию
4. проверьте данные в **Dashboards**, **Analytics** и **Logs**

### Что настраивается

* тип кампании и источник трафика
* домен и лендинг
* параметры и фильтры
* маршрут пользователя
* ссылки для запуска трафика

### Типы кампаний

* **Not Organic** — для платного трафика и передачи параметров
* **Organic** — для органического трафика без стандартной трекинговой разметки

### Что видно в списке

В карточке кампании отображаются:

* статус кампании
* тип трафика и источник
* домен и лендинг
* **Invite Bot**, **DM bot**, Telegram-канал
* buyer
* метрики `SUBS`, `DIA`, `REG`, `DEP`

### Доступные действия

* **Links** — получить ссылки запуска
* **Edit** — открыть настройки
* **Duplicate** — создать копию
* **Stop** — остановить кампанию

{% hint style="warning" %}
**Stop** останавливает кампанию, но не удаляет её.
{% endhint %}
