# Test - раздел campaign

> ### Test - это раздел для проверки кампании перед запуском рекламы.

{% hint style="info" %}
С его помощью можно:

* проверить, что ссылка кампании работает корректно
* убедиться, что лендинг открывается без ошибок
* проверить фильтрацию и маршрут пользователя
* убедиться, что события фиксируются в Tracker
*   Скриншот раздела `Test`:

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image 32590.png" alt="Скриншот раздела Test"><figcaption></figcaption></figure></div>
{% endhint %}

### Как работает Test:

{% hint style="info" %}
При тестовом открытии система имитирует обычный заход пользователя по рекламной ссылке.
{% endhint %}

{% hint style="info" %}
Это позволяет заранее проверить:

* открытие лендинга
* применение фильтров
* переход в канал или бота
* запуск нужного сценария
* фиксацию событий в Tracker
{% endhint %}

### Как использовать Test:

{% stepper %}
{% step %}
{% hint style="info" %}
**Откройте кампанию**

Перейдите в нужную кампанию в разделе `Campaigns`.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Перейдите во вкладку Test**

Откройте раздел `Test` внутри кампании.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Запустите проверку**

Нажмите `Open`, чтобы открыть тестовую ссылку.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Проверьте поведение кампании**

Убедитесь, что переход проходит по ожидаемому сценарию.
{% endhint %}
{% endstep %}
{% endstepper %}

### Важно:

<details>

<summary>Что рекомендуется проверить</summary>

{% hint style="info" %}
Во время теста проверьте:

* открывается ли лендинг
* работает ли фильтрация
* происходит ли переход в бот или канал
* запускается ли нужный Flow и Step
* фиксируются ли события в Tracker
{% endhint %}

</details>

<details>

<summary>Когда использовать Test</summary>

{% hint style="info" %}
Используйте Test перед:

* каждым новым запуском
* сменой лендинга
* изменением логики кампании
{% endhint %}

</details>

<details>

<summary>Важные особенности</summary>

{% hint style="warning" %}
Тестовый переход имитирует реальный заход пользователя.

Все события, полученные во время проверки, могут записываться в статистику кампании.
{% endhint %}

</details>

### Где удобно использовать Test:

{% hint style="success" %}
Test удобно использовать, когда нужно:

* проверить кампанию до запуска трафика
* убедиться, что маршрут пользователя работает правильно
* найти ошибку до старта рекламы
* проверить фиксацию событий после изменений
{% endhint %}
