# Как фильтровать данные

## Как фильтровать данные

Фильтрация помогает быстро найти нужный срез трафика в Analytics. Она работает по параметрам ссылки, кампании, дате и группировке.

### Как это работает

Фильтры находятся в блоке `Filters` над таблицей Analytics. Они помогают найти нужный сегмент без ручного поиска по всей таблице.

![Блок Filters в Analytics](<../../../.gitbook/assets/unknown (96).png>)

С помощью фильтрации можно:

* быстро находить нужный сегмент трафика
* фильтровать данные по параметрам ссылки
* добавлять условия по кампании и дате
* группировать статистику по нужному параметру

### Как применить фильтр

1. Откройте блок `Filters`.
2. Укажите нужные параметры для отбора трафика.
3. При необходимости выберите `Campaign`, `Date` и `Group By`.
4. Нажмите `Search`.

После этого таблица и метрики обновятся по выбранным условиям.

### Какие параметры можно фильтровать

Можно использовать любые параметры, которые передаются в ссылке залива.

Например:

* `campaign_name`
* `ad_campaign_id`
* `adset_id`
* `ad_name`
* `placement`
* `utm_source`
* `utm_campaign`
* `utm_content`
* `keyword`
* `source_name`
* `buyer`
* другие параметры

### Как работает Group By

`Group By` группирует статистику по выбранному параметру. Это удобно для анализа эффективности отдельных связок и источников.

![Поле Group By](<../../../.gitbook/assets/unknown (97).png>)

Группировка работает, например, по:

* `Day`
* `source_name`
* `ad_name`
* `buyer`
* UTM-меткам
* другим параметрам из ссылки

### Как использовать Filters и Group By вместе

Сначала сузьте выборку через `Filters`. Затем сгруппируйте данные по нужному параметру через `Group By`.

### Где использовать фильтрацию

Фильтрация полезна, когда нужно:

* найти нужную кампанию или связку
* сравнить результаты по `buyer`, `source` или UTM
* сузить данные перед выгрузкой
* разобрать конкретный сегмент трафика
