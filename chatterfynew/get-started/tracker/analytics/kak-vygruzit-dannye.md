# Как выгрузить данные

## Как выгрузить данные

Выгрузка данных позволяет сохранить текущую статистику в файл.

### Как это работает

Экспорт формирует файл на основе текущих данных в Analytics. Он учитывает активные фильтры, период и выбранную группировку.

![Кнопка Export CSV](<../../../.gitbook/assets/Frame 2109 (1).png>)

### Как выгрузить данные

1. Откройте Analytics.
2. Проверьте нужные фильтры, период и группировку.
3. Нажмите **Export CSV**.

### Что попадёт в файл

В файл попадут все текущие данные:

* с учётом выбранных фильтров
* выбранного периода
* применённой группировки

### Для чего использовать CSV-файл

CSV-файл удобно использовать для:

* подготовки отчётов
* сверки данных
* загрузки в сторонние аналитические системы
