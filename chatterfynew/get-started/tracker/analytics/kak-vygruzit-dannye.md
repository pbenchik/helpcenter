# Как выгрузить данные

> ### **Выгрузка данных** позволяет сохранить текущую статистику в файл.

{% hint style="info" %}
Чтобы выгрузить статистику, нажмите кнопку **Export CSV**.

*   Скриншот кнопки `Export CSV`:

    ![Кнопка Export CSV](<../../../.gitbook/assets/Frame 2109 (1).png>)
{% endhint %}

### Что попадёт в файл:

{% hint style="info" %}
Будет сформирован файл со всеми текущими данными:

* с учетом выбранных фильтров
* выбранного периода
* примененной группировки
{% endhint %}

### Для чего использовать CSV-файл:

{% hint style="info" %}
CSV-файл можно использовать для:

* подготовки отчетов
* сверки данных
* загрузки в сторонние аналитические системы
{% endhint %}
