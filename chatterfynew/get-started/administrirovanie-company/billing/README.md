# Billing

## Billing

Billing используется для управления балансом компании и отслеживания расходов внутри платформы.

### Как это работает

В разделе **Billing** можно пополнять баланс, контролировать списания средств и анализировать использование ресурсов.

![Раздел Billing](<../../../.gitbook/assets/Frame 2050.png>)

### Особенности биллинга

* списание средств происходит раз в сутки в `00:00` по `UTC+0`
* пополнение баланса доступно только в `USDT`
* поддерживаемые сети:
  * `TRC20`
  * `ERC20`

### Что отображается в интерфейсе

В верхней части раздела отображается основная информация по биллингу компании:

* **Balance** — текущий баланс компании
* **Full usage for the period** — общий расход за текущий период
* **Month expense** — расходы за последние 30 дней
* **All bots** — общее количество ботов
* **Billing bots** — количество ботов, участвующих в биллинге
* **Not billing bots** — боты, которые не учитываются в расходах
