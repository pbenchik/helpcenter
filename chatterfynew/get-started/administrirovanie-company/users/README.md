# Users

Раздел **Users** нужен для управления сотрудниками внутри компании.

Здесь вы приглашаете пользователей, назначаете роли и выдаёте доступ к **Spaces**.

### Где находится

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image 32556.png" alt=""><figcaption></figcaption></figure></div>

Откройте **Company → Users**.

### Как работает раздел

Основной экран показывает таблицу пользователей компании.

Права доступа зависят от роли на уровне компании. Список ролей смотрите в разделе [Роли пользователей](roli-polzovatelei.md).

### Поля таблицы

* **Name** — имя пользователя.
* **Role** — роль пользователя на уровне компании.
* **Spaces** — пространства, к которым у пользователя есть доступ.
* **Last activity** — время последней активности пользователя.
* **Joined** — дата присоединения к компании.
* **Invited by** — кто отправил приглашение.
* **Actions** — действия с пользователем. Набор зависит от вашей роли.
