# Сделал импорт флоу, поменял часть шагов, но бот все равно ведет по старой воронке

{% hint style="info" %}
После импорта важно проверять настройки шагов Change flow, Custom condition, а также шаги Send Message, где настроены **Inline Buttons** или **Keyboard**. Эти настройки **не переносятся** между ботами и личками.
{% endhint %}
