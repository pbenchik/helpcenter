# Требования к загрузке кастомного ленда

> ### Как корректно добавить кастомный ленд на платформу ? Нужно ли вшивать ссылку в кнопку на кастомном лендинге ?

{% hint style="info" %}
Для того, что бы добавить кастомный лендинг на платформу, Вам необходимо загрузить архив в формате ZIP, содержащий файл index.html в корне данного архива.

Ссылки в кнопки вшивать не нужно, Вам необходимо только добавить кнопку для перехода в Telegram, указав атрибут tracker у соответствующего элемента. И таких элементов может быть сколько угодно, можно хендлить любое количество кнопок

Пример: `< a tracker > * Ваша кнопка * < / a>`
{% endhint %}
