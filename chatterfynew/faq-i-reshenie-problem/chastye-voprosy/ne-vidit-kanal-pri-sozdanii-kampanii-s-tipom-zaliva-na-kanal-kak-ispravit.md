# Не видит канал при создании кампании с типом залива "На канал", как исправить ?

{% hint style="info" %}
Сначала проверьте:\
нет ли в канале других ботов, которые принимают заявки;\
не подключён ли этот бот к другому сервису.

Если ничего из этого нет, удалите бота из канала и добавьте его заново с правами администратора
