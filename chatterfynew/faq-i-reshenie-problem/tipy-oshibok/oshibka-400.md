# Ошибка 400

> ### rpc error code 400: PEER\_FLOOD

{% hint style="info" %}
Данная ошибка означает спам-блок. Она возникает, **когда с аккаунта слишком часто или массово отправляются сообщения** - в этот момент срабатывает антиспам-защита Telegram.

\
При этом это не всегда блокировка всей лички. Иногда ограничение может появляться только в одном или нескольких чатах или распространяться только на конкретную сессию. В некоторых случаях такие ограничения бывают временными.\
Чтобы снизить вероятность подобных ограничений, рекомендуется уменьшать нагрузку, увеличивать паузы между сообщениями и разнообразить тексты. Также можно использовать Telegram Premium и постепенно прогревать Ваши лички.
{% endhint %}

> ### Error: telego: sendMediaGroup: api: 400 "Bad Request: message caption is too long

{% hint style="info" %}
Данная ошибка возникает, когда описание (caption) к медиафайлу **превышает допустимую длину**. В таком случае Telegram не отправляет сообщение.

Ограничения по длине текста:\
Если отправляется медиафайл с подписью (caption) - **текст под фото или видео не должен превышать 1024 символа.**\
Если отправляется обычное текстовое сообщение без медиа - лимит в Telegram составляет 4096 символов.

При этом на нашей платформе **установлен дополнительный лимит до 3000 символов для одного сообщения.**\
Если текст превышает указанные ограничения, его необходимо сократить или разделить на несколько сообщений.
{% endhint %}
