# Ошибка 403

> ### Сообщение не отправляется, ошибка 403 Forbidden: Bot can't initiate conversation with a user

{% hint style="info" %}
Эта ошибка возникает из-за технического ограничения Telegram.\
<mark style="color:$warning;">У бота есть окно размером в 5 минут</mark> после принятия пользователя в канал для того, чтобы написать ему. После - нужно сообщение от пользователя (либо нажатие на кнопку типа keyboard), чтобы бот мог писать дальше.\
Если этого нет - возникает подобная ошибка.
{% endhint %}

> ### Error: 403 Forbidden: user is deactivated

{% hint style="info" %}
Оно может и не всегда распространятся на всю личку\
Может встретится в одном или двух чатах\
И распространятся конкретно на одну сессию, также как и баны временные тг
{% endhint %}
