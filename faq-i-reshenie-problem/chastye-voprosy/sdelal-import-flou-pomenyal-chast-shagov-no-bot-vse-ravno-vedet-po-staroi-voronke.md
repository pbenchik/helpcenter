# Сделал импорт флоу, поменял часть шагов, но бот все равно ведет по старой воронке

{% hint style="info" %}
После импорта важно проверять настройки шагов Change flow, Custom condition, а также шаги Send Message, в которых есть тип сообщения Inline Buttons или Keyboard. Так как настройки этих шагов **не переносятся** между ботами/личками.
{% endhint %}
