# Тестовый период

> ### Полноценного тестового периода для всей платформы нет.
>
> ### Тестовый доступ предоставляется только для подключённых ботов.



### Как работает тестовый период?

После подключения бота начинается тестовый период.

Он действует до первого выполненного условия:

* бот обработает <mark style="color:$warning;">**25 диалогов**</mark>
* с момента подключения пройдёт <mark style="color:$warning;">**7 дней**</mark>

Какое условие наступит раньше, по нему и завершится тестовый период.

{% hint style="danger" %}
Тестовый период считается отдельно для подключённого бота, а не для всей компании.
{% endhint %}

### Когда тест заканчивается?

Тестовый доступ завершается автоматически.

После этого для дальнейшей работы потребуется <mark style="color:$warning;">активация и пополнение баланса.</mark>

{% hint style="danger" %}
Если бот быстро набирает 25 диалогов, тестовый период может закончиться раньше 7 дней.
{% endhint %}
