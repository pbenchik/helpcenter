# Как создать аккаунт

> #### Чтобы начать работу с Chatterfy, нужно зарегистрировать аккаунт, создать компанию и активировать её.

{% hint style="info" %}
Видео инструкция как зарегистрировать аккаунт, создать компанию и активировать её.

{% embed url="https://www.youtube.com/watch?v=UDfceUEnKFs" %}

***

00:13 - Регистрация

***

00:53 - Создание компании

***
{% endhint %}

{% hint style="warning" %}
Для активации нужен демо-звонок и первое пополнение от **100 USD**.
{% endhint %}

{% stepper %}
{% step %}
### Порядок регистрации

{% hint style="info" %}
* #### Перейдите на страницу регистрации: [app.chatterfy.ai/signin](https://app.chatterfy.ai/signin)

Укажите:

* email
* пароль
{% endhint %}

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2129.png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
* #### После регистрации на почту придёт код подтверждения.
* Введите его, чтобы завершить создание аккаунта.
{% endhint %}

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2130.png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
{% hint style="info" %}
* #### Свяжитесь с менеджером

Для активации компании напишите менеджеру Chatterfy:

[**t**.me/chatterfyai](https://t.me/chatterfyai)

Менеджер поможет:

* активировать аккаунт
* объяснить следующие шаги
* ответить на вопросы по платформе
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* #### Пройдите демо-звонок

Перед активацией проводится обязательный демо-звонок.

Во время звонка:

* показывают основные возможности платформы
* объясняют условия работы
* разбирают ваш кейс
* отвечают на вопросы по настройке
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* #### Пополните баланс

Для активации компании пополните баланс минимум на **100 USD**.

Доступные сети:

* `ERC20`
* `TRC20`

После пополнения компания активируется.
{% endhint %}
{% endstep %}
{% endstepper %}

### Важно:

{% hint style="danger" %}
Без демо-звонка и первого пополнения компания не активируется.
{% endhint %}
