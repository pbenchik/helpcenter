# Change flow

> ### Change Flow - это шаг для перевода пользователя в другой flow.

Здесь выбирается сценарий и конкретный шаг, с которого продолжится диалог.

{% hint style="info" %}
*

    <div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Frame 2260 (4).png" alt=""><figcaption></figcaption></figure></div>

Change Flow используют, когда нужно:

* разделить пользователей по разным сценариям
* перенаправить диалог в другую воронку
* переиспользовать уже готовые flow
* упростить структуру сложных сценариев

Этот шаг помогает собирать несколько логик в одну систему без дублирования.
{% endhint %}

{% hint style="warning" %}
После выполнения шага текущий сценарий прекращается.

Пользователь сразу переходит в выбранный flow и на выбранный шаг.

Новый flow начинает работу именно с этого места.
{% endhint %}

### Как работает Change Flow:

{% hint style="info" %}
1. Система доходит до шага **Change Flow**.
2. Берёт flow, который выбран в настройках.
3. Переводит пользователя на указанный шаг внутри этого flow.
4. Продолжает диалог уже в новом сценарии.

Это удобно для развилок, сегментации и перехода между воронками.
{% endhint %}

### 1. Settings (Настройки):

{% hint style="info" %}
В блоке **Settings** задаются общие параметры шага:

* **Title** — название шага
* **Delay** — задержка перед выполнением перехода
* **Finish Status** — статус диалога после выполнения шага
* **Hide keyboard** — скрывает клавиатуру из предыдущего шага
* **Is start step of flow** — делает шаг стартовым
* **Skip the transition to next step** — отключает автоматический переход дальше
*

    <div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

{% hint style="warning" %}
Во время `Delay`:

* сообщения пользователя игнорируются
* переход в другой flow не выполняется
{% endhint %}

{% hint style="warning" %}
Если вы используете статус `waiting`, можно включить **Skip the transition to next step**.

Тогда шаг не переключится автоматически и система останется на текущем состоянии до нужного действия.
{% endhint %}

### 2. Flow (Переход в другой сценарий):

{% hint style="info" %}
В этом блоке настраивается сам переход:

* **Choose flow** — выбор flow, в который нужно перевести пользователя
* **Choose step** — выбор конкретного шага внутри этого flow
*

    <div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Frame 2248 (66).png" alt=""><figcaption></figcaption></figure></div>

Если flow выбран правильно, пользователь сразу продолжит путь в новом сценарии.

Это позволяет:

* разделять пользователей по странам, источникам или интересам
* отправлять трафик в отдельные воронки
* собирать сложную архитектуру из нескольких flow
{% endhint %}

### Как AI учитывает этот шаг:

{% hint style="info" %}
Change Flow не генерирует сообщение пользователю.

Он только меняет маршрут диалога и передаёт пользователя в другой сценарий.

Поэтому здесь важно не содержание текста, а точность выбора нужного flow и шага.
{% endhint %}

{% hint style="warning" %}
Если выбрать не тот flow или не тот шаг, пользователь попадёт в неправильную часть сценария.

Проверяйте, что переход ведёт в актуальную воронку и в нужную точку логики.
{% endhint %}

### Пример использования:

{% hint style="info" %}
Сценарий: разделение пользователей по регионам.

* Пользователь из Европы → перевод в flow `EU Funnel`
* Пользователь из Азии → перевод в flow `ASIA Funnel`

Так можно быстро разнести аудиторию по разным сценариям общения.
{% endhint %}

### Когда использовать Change Flow:

{% hint style="success" %}
Используйте этот шаг, когда нужно:

* перевести пользователя в другой flow
* отправить его сразу на нужный шаг
* разделить логику между несколькими сценариями
* переиспользовать готовые воронки вместо копирования шагов
{% endhint %}
