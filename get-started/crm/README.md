# CRM

> ### CRM в Chatterfy объединяет общение с клиентами, работу с лидами и управление базой пользователей.

Здесь команда ведёт переписку, меняет статусы, запускает рассылки и отслеживает данные по каждому клиенту.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/Frame 2112.png" alt=""><figcaption></figcaption></figure></div>

### Что можно делать в CRM:

{% hint style="info" %}
* вести диалоги с клиентами
* хранить данные по пользователям
* назначать менеджеров
* менять статусы и теги
* фильтровать и сегментировать базу
* запускать массовые рассылки
* смотреть историю действий и трекинг-данные
{% endhint %}

### Как обычно работают в CRM:

{% stepper %}
{% step %}
#### Обрабатывают диалоги

{% hint style="info" %}
Команда отвечает клиентам, разбирает обращения и ведёт переписку в одном месте.
{% endhint %}
{% endstep %}

{% step %}
#### Работают с базой пользователей

{% hint style="info" %}
В CRM можно искать клиентов, фильтровать сегменты и смотреть нужные данные по каждому пользователю.
{% endhint %}
{% endstep %}

{% step %}
#### Запускают рассылки

{% hint style="info" %}
Когда база готова, команда отправляет массовые сообщения по выбранным сегментам.
{% endhint %}
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
CRM особенно полезен, когда нужно одновременно вести чаты, контролировать воронку и работать с большой базой пользователей.
{% endhint %}
