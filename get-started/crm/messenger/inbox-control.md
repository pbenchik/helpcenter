# Inbox Control

> ### Inbox Control помогает быстро работать со списком чатов в Messenger.

Здесь можно переключаться между вкладками, фильтровать диалоги и сохранять нужные выборки.

### **Основные вкладки**:

{% hint style="info" %}
В верхней части раздела доступны основные вкладки для работы с чатами.

*

    <figure><img src="../../../.gitbook/assets/Frame 2220.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

### **All — список всех чатов в боте или личке**:

<figure><img src="../../../.gitbook/assets/Frame 2174.png" alt=""><figcaption></figcaption></figure>

### **My Chats — чаты, которые назначены на вас**:

{% hint style="info" %}
* Вкладка **My Chats** используется, когда работа распределяется между менеджерами или обработчиками.
* Так проще видеть только свои диалоги и не отвлекаться на общий поток.
*

    <figure><img src="../../../.gitbook/assets/Frame 2221.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

### **Favorites — избранные чаты для быстрого доступа**:

{% hint style="info" %}
Как добавить чат в **Favorites**:

1. Откройте нужный чат.
2. Нажмите на значок `⭐️` слева от аватарки.\ После этого:

* чат появится во вкладке **Favorites**
* в общем списке у пользователя появится значок звезды на аватарке
*

    <figure><img src="../../../.gitbook/assets/Frame 2222.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

### **Chat Status**:

{% hint style="info" %}
* Блок **Chat Status** нужен для быстрой фильтрации чатов по статусам.
* Он помогает сразу отделить новые, активные и завершённые диалоги.
*

    <figure><img src="../../../.gitbook/assets/Frame 2137.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

### **3. Фильтрация**:

{% hint style="info" %}
* Фильтры помогают быстро находить нужных пользователей по заданным параметрам.
* Чтобы открыть фильтры, нажмите кнопку **Filters**.
*

    <figure><img src="../../../.gitbook/assets/Frame 2223.png" alt=""><figcaption></figcaption></figure>

Доступные параметры фильтрации:

* **Flow** — текущий флоу
* **Step** — шаг пользователя
* **Chat Status** — статус чата
* **Assign** — назначенный менеджер
* **Date** — дата создания чата
{% endhint %}

### Если фильтр нужен регулярно, его можно сохранить:

{% hint style="info" %}
* Для этого нажмите **Save Filter**. После сохранения он появится во вкладке **My Filters**.
*

    <figure><img src="../../../.gitbook/assets/Frame 2224.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

### **My Filters и Custom Filters**:

{% hint style="info" %}
* **My Filters** — это личные фильтры пользователя.
* сохраняются отдельно для каждого сотрудника
* не видны другим пользователям
{% endhint %}

### **Custom Filters — это общие фильтры внутри бота**:

{% hint style="info" %}
* доступны всем пользователям с доступом к боту
* настраиваются отдельно
* подходят для общей командной работы
{% endhint %}
