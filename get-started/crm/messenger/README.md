# Messenger

> Messenger — это основной раздел CRM для работы с диалогами.
>
> Здесь команда отвечает клиентам, управляет статусами чатов и быстро находит нужные диалоги.

{% hint style="info" %}
Используйте Messenger, когда нужно вести переписку, сортировать чаты и работать с данными клиента в одном окне.
{% endhint %}

### Что есть в разделе:

{% hint style="info" %}
* список всех диалогов
* фильтры и сохранённые выборки
* статусы чатов
* быстрые шаблоны сообщений
* встроенный переводчик
* карточка клиента с данными и действиями
{% endhint %}

### Краткая выжимка по подвкладкам:

{% hint style="info" %}
<a href="inbox-control.md" class="button secondary" data-icon="inbox-full">Inbox Control</a>

Управление списком чатов.

Здесь есть вкладки `All`, `My Chats`, `Favorites`, фильтры и сохранённые выборки.
{% endhint %}

{% hint style="info" %}
<a href="chat-status.md" class="button secondary" data-icon="chart-simple-horizontal">Chat status</a>

Статусы показывают текущее состояние диалога.

Через них команда понимает этап общения и фильтрует чаты по нужному сценарию.
{% endhint %}

{% hint style="info" %}
<a href="custom-filters/" class="button secondary" data-icon="bookmark">Custom Filters</a>

Общие фильтры для бота или личного аккаунта.

Подходят для командной работы, когда нужно быстро находить лидов по тегам, шагам, событиям и другим параметрам.
{% endhint %}

{% hint style="info" %}
<a href="perevodchik.md" class="button secondary" data-icon="earth-americas">Переводчик</a>

Встроенный перевод входящих и исходящих сообщений.

Помогает работать с разными языками прямо внутри чата.
{% endhint %}

{% hint style="info" %}
<a href="templates.md" class="button secondary" data-icon="block">Templates</a>

Шаблоны сообщений для быстрых ответов.

Операторы могут вызывать их через `#`, хранить по категориям и импортировать из других ботов.
{% endhint %}

{% hint style="info" %}
<a href="kartochka-klienta/" class="button secondary" data-icon="clipboard">Карточка клиента</a>

Рабочая карточка конкретного лида.

Здесь собраны данные пользователя, история общения и инструменты управления диалогом.
{% endhint %}

{% hint style="warning" %}
Если вы только начинаете, сначала откройте [`Inbox Control`](inbox-control.md), затем изучите [`Chat status`](chat-status.md) и [`Карточка клиента`](kartochka-klienta/).
{% endhint %}
