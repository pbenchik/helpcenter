# Events

> ### Раздел Events позволяет отслеживать действия пользователя и его путь воронке в реальном времени.

{% hint style="info" %}
Это дает точную картину поведения лида и помогает оптимизировать воронку и эффективно управлять диалогом.

Show events- позволяет включить / выключить отображение конкретных событий во вкладке Events.

*   <br>

    <div data-with-frame="true"><figure><img src="../../../../../.gitbook/assets/Frame 2244.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### **Типы событий**:

{% hint style="info" %}
* **Page View** - пользователь просмотрел лендинг после перехода по ссылке из кампании
* **Click** - Click - нажатие по кнопке на ленлинге.

Если в настройках кампани у вас включена функция Auto redirect, то данное событие не фиксируется.
{% endhint %}

### **Subscribe - подписка.**

{% hint style="info" %}
При заливе на канал - фиксируется в момент принятия заявки ботом-автоприемщиком

При заливе на бота - фиксируется в момент, когда пользователь запускает бота.

* **Contact -** Пользователь написал текстовое сообщение, либо отправил медиа/эмоджи, либо нажал в боте кнопку типа Keyboard
{% endhint %}

### Registration - регистрация пользователя.

{% hint style="info" %}
FD / RD - первый депозит / повторный депозит

**Могут фиксироваться:**

* Вручную
* Через шаг Send Event
* Автоматически через Postback
{% endhint %}
