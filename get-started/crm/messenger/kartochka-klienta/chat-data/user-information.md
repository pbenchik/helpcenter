# User information

> ### В блоке User Information отображается базовая информация о пользователе:

{% hint style="info" %}
* **username** клиента
* **дата и время начала диалога**
* **Step ID** - идентификатор текущего шага
* **Chat ID** - уникальный идентификатор чата
