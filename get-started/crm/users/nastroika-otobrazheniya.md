# Настройка отображения

> ### **С помощью кнопки Columns можно настроить отображение полей в таблице пользователей.**

{% hint style="info" %}
**Набор отображаемых данных можно менять через Columns.**

*

    <figure><img src="../../../.gitbook/assets/Frame 2249.png" alt=""><figcaption></figcaption></figure>
*

    <figure><img src="../../../.gitbook/assets/Frame 2248 (49).png" alt=""><figcaption></figcaption></figure>
{% endhint %}

{% hint style="info" %}
Через **Columns** можно включать:

* кастомные поля — <a href="../../bot-settings/custom-fields.md" class="button secondary">подробнее про Custom Fields</a>
* трекерные поля — <a href="../messenger/kartochka-klienta/chat-data/tracker-data.md" class="button secondary">подробнее про Tracker Fields</a>
* другие дополнительные колонки, нужные для работы
{% endhint %}

{% hint style="warning" %}
Это позволяет адаптировать таблицу под конкретные задачи команды.

Например, вывести только те поля, которые нужны для обработки, аналитики или сегментации.
{% endhint %}
