# Как создать и настройть рассылку

> ### Создать рассылку можно из раздела **Users**.
>
> ### При необходимости сначала отфильтруйте нужную аудиторию, а затем создайте рассылку для выбранных пользователей.

### Как создать рассылку:

{% step %}

### Подробнее:

<details>

<summary>1. Основная информация</summary>

{% hint style="info" %}
После создания откроется форма настройки рассылки.

<img src="../../../.gitbook/assets/unknown (150).png" alt="" data-size="original">

В блоке **Основная информация** указывается:

* **Mailing Name** — внутреннее название рассылки
{% endhint %}

</details>

<details>

<summary>2. Сообщения</summary>

{% hint style="info" %}
В рассылку можно добавить одно или два сообщения.

<img src="../../../.gitbook/assets/unknown (151).png" alt="" data-size="original">
{% endhint %}

{% hint style="info" %}
Для текста доступна функция **Uniquify with AI**.

Она помогает сгенерировать несколько вариантов одного сообщения.

Для этого:

* задаётся промпт
* указывается **Answers Count** — количество вариантов

<img src="../../../.gitbook/assets/unknown (152).png" alt="" data-size="original">
{% endhint %}

</details>

<details>

<summary>3. Sending Options</summary>

{% hint style="info" %}
В блоке **Sending Options** задаётся задержка между отправкой сообщений.

**Delay Between Messages (sec)** — задержка между сообщениями в секундах.
{% endhint %}

{% hint style="info" %}
Пример:

Если указать задержку `60` секунд:

* 1-й пользователь получит сообщение сразу
* 2-й — через 60 секунд
* 3-й — через 120 секунд
* и так далее
{% endhint %}

</details>

<details>

<summary>4. Отложенная отправка</summary>

{% hint style="info" %}
Функция **Schedule Sending** позволяет задать дату и время старта рассылки.

<img src="../../../.gitbook/assets/unknown (153).png" alt="" data-size="original">
{% endhint %}

</details>

<details>

<summary>5. Review</summary>

{% hint style="info" %}
Перед запуском отображается итоговая информация по рассылке.

В review-блоке можно проверить:

* название
* сообщения
* задержки
* примерная длительность
* и другие параметры перед отправкой
{% endhint %}

</details>

{% hint style="warning" %}
Перед запуском проверьте выбранную аудиторию и текст сообщений.

После старта рассылка уйдёт всем выбранным пользователям по заданным настройкам.
{% endhint %}
