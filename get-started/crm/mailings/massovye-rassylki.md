# Массовые рассылки

> ### Массовые рассылки позволяют отправлять сообщения выбранной базе пользователей. Сообщения отправляются последовательно, с учётом заданных настроек отправки.

***

{% hint style="info" %}
{% embed url="https://youtu.be/73wgcPJO3yg" %}

В рассылках поддерживаются следующие форматы:

* **Text** — текстовые сообщения
* **Media** — изображения и видео
* **Document** — документы
* **Video Note** — видео-кружки
* **Voice** — голосовые сообщения
* **Audio** — аудиофайлы
{% endhint %}

{% hint style="info" %}
Рассылки удобно использовать для:

* повторного контакта с базой
* уведомлений по сегменту пользователей
* отправки одного сообщения сразу нескольким получателям
{% endhint %}
