# Company - управление компанией

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2115.png" alt=""><figcaption></figcaption></figure></div>

**Company** — это раздел для управления компанией на уровне всей платформы.

Здесь находятся общие настройки, пользователи, биллинг и контроль доступа.

### Что управляется в Company:

{% hint style="info" %}
В этом разделе обычно настраивают:

* компанию и её базовые параметры
* баланс и историю списаний
* пользователей и роли
* доступ к рабочим пространствам
* системные логи
{% endhint %}

### Когда использовать Company:

{% hint style="info" %}
Раздел **Company** нужен, когда вы хотите:

* пригласить сотрудников
* выдать роли и права доступа
* пополнить баланс компании
* проверить историю операций
* создать или контролировать Spaces
{% endhint %}

{% hint style="info" %}
Если настройка относится ко всей компании, её нужно искать в разделе **Company**.
{% endhint %}

### Какую роль Company играет в системе?

{% stepper %}
{% step %}
#### Управление компанией

{% hint style="warning" %}
Сначала на уровне Company настраивается сама организация вашей команды.
{% endhint %}
{% endstep %}

{% step %}
#### Управление доступом

{% hint style="warning" %}
Затем добавляются пользователи, назначаются роли и распределяется доступ к разделам.
{% endhint %}
{% endstep %}

{% step %}
#### Управление Spaces

{% hint style="warning" %}
После этого создаются отдельные рабочие пространства.
{% endhint %}
{% endstep %}
{% endstepper %}
