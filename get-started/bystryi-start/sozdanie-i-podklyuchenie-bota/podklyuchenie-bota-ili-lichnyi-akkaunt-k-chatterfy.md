# Подключение бота или личный аккаунт к Chatterfy

> ### Подключение выполняется через раздел **CRM**. Там можно добавить Telegram-бота или личный аккаунт.

### Что нужно до начала:

{% hint style="info" %}
* #### Перед подключением подготовьте:
* токен Telegram-бота, если подключаете бота
* номер телефона или QR-код, если подключаете личный аккаунт
* Space, в котором будет работать подключение
{% endhint %}

{% hint style="info" %}
Если вы ещё не создали бота, сначала пройдите шаг создания в Telegram.
{% endhint %}

### Как подключить бота или личный аккаунт:

{% stepper %}
{% step %}
{% hint style="info" %}
* #### Откройте создание нового подключения

Перейдите в раздел **CRM** и нажмите **Create New Bot**.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
* #### Выберите платформу

Сейчас доступен **Telegram**.

Позже будут доступны Instagram, WhatsApp, Facebook и другие платформы.

{% endstep %}

{% endhint %}
{% endstep %}

{% step %}

* #### Укажите основные данные
