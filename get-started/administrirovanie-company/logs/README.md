# Logs

> ### Logs — это журнал действий пользователей внутри компании.

![Журнал действий компании](<../../../.gitbook/assets/image 32558.png>)

#### С помощью Logs можно

{% hint style="info" %}
* отслеживать административные действия внутри компании
* проверять, кто и что изменил
* разбирать спорные ситуации и инциденты
* проводить внутренний аудит действий команды
{% endhint %}

#### Что отображается в Logs

{% hint style="info" %}
Основной экран раздела — это таблица событий.

В ней отображаются:

* Event — тип события
* User — пользователь, который выполнил действие
* Object — объект системы, к которому относится событие
* Details — детали изменения
* Timestamp — дата и время события
{% endhint %}

<details>

<summary>Какие события попадают в Logs</summary>

{% hint style="info" %}
В Logs записываются действия, которые влияют на работу компании.

Частые примеры:

* приглашение пользователей
* изменение ролей
* удаление пользователей
* создание и изменение ботов
* другие административные действия
{% endhint %}

</details>

<details>

<summary>Как использовать Logs в работе</summary>

{% hint style="info" %}
Раздел помогает быстро восстановить цепочку действий.

Например, здесь можно:

* найти автора конкретного изменения
* проверить время события
* понять, какой объект был изменён
{% endhint %}

</details>

<details>

<summary>Фильтрация и выгрузка</summary>

{% hint style="info" %}
Для работы с большим количеством событий используйте:

* [Как фильтровать Logs](kak-filtrovat-logs.md)
* [Как выгрузить Logs](kak-vygruzit-logs.md)
{% endhint %}

</details>

### Когда удобно использовать Logs

{% hint style="success" %}
**Logs удобно использовать, когда нужно:**

* проверить историю действий внутри компании
* найти автора изменения
* отследить административные события
* подготовить данные для проверки или отчёта
{% endhint %}
