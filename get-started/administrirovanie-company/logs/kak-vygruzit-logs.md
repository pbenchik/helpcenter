# Как выгрузить Logs

> ### **С помощью выгрузки логов можно получить подробную CSV-таблицу со всеми нужными вам логами.**

{% hint style="info" %}
Экспорт делает `CSV` из текущей таблицы событий.

*

    <figure><img src="../../../.gitbook/assets/Frame 2099.png" alt=""><figcaption></figcaption></figure>
{% endhint %}

{% stepper %}
{% step %}
### Примените фильтры (опционально)

{% hint style="warning" %}
Если нужно выгрузить только часть событий, сначала настройте фильтры.
{% endhint %}
{% endstep %}

{% step %}
### Нажмите Export CSV

{% hint style="warning" %}
Система сформирует файл и начнёт загрузку.
{% endhint %}
{% endstep %}
{% endstepper %}

{% hint style="info" %}
<mark style="color:$primary;">CSV формируется с учётом текущих фильтров и периода.</mark>
{% endhint %}

### Зачем нужен CSV

{% hint style="info" %}
* внутренняя отчётность
* анализ действий сотрудников
* аудит и разбор инцидентов
{% endhint %}
