### Подробнее про разделы:

<details>

<summary>Основные показатели</summary>

{% hint style="info" %}
В верхней части страницы отображаются ключевые метрики:

* `Clicks` — количество кликов по кнопкам на лендинге
* `Subscribers` — пользователи, подписавшиеся на канал или запустившие бота
* `Dialogues` — пользователи, по которым получено событие `contact`
* `Registration` — количество регистраций
* `FD` — количество первых депозитов
* `RD` — количество повторных депозитов
{% endhint %}

{% hint style="info" %}
После изменения фильтров показатели пересчитываются автоматически.
{% endhint %}

</details>

<details>

<summary>Трафик</summary>

{% hint style="info" %}
В таблице аналитики доступны показатели трафика:

* `PAGE VIEWS` — количество открытий лендинга
* `CTR` — соотношение просмотров лендинга к кликам
* `CLICKS` — количество кликов по кнопке на лендинге
{% endhint %}

</details>

<details>

<summary>Подписки</summary>

{% hint style="info" %}
Показатели подписок:

* `VIEWS2SUB` — конверсия из просмотра лендинга в подписку
* `CLICKS2SUB` — конверсия из клика в подписку
* `SUBSCRIBES` — общее количество подписок
* `NET CLICK2SUB` — чистая конверсия кликов в подписку с учётом отписок
* `NET SUBSCRIBES` — чистый прирост подписчиков
{% endhint %}

</details>

<details>

<summary>Диалоги и регистрации</summary>

{% hint style="info" %}
Показатели диалогов и регистраций:

* `SUB2DIA` — конверсия из подписки в диалог
* `DIALOGUES` — количество пользователей, по которым получено событие `contact`
* `DIA2REG` — конверсия из диалога в регистрацию
* `REGISTRATIONS` — количество регистраций
{% endhint %}

</details>

<details>

<summary>Депозиты</summary>

{% hint style="info" %}
Показатели депозитов:

* `REG2FD` — конверсия из регистрации в первый депозит
* `DIA2FD` — конверсия из диалога в первый депозит
* `FD` — количество первых депозитов
* `FD2UNIQRD` — конверсия из первого депозита в уникальный повторный депозит
* `UNIQUE RD` — количество пользователей, совершивших повторный депозит
* `FD2RD` — конверсия из первого депозита в повторные депозиты
* `RD` — общее количество повторных депозитов
{% endhint %}

</details>

<details>

<summary>Строка Total</summary>

{% hint style="info" %}
Строка `Total` показывает суммарные значения по всем выбранным кампаниям и применённым фильтрам.
{% endhint %}

</details>

### Где удобно использовать Analytics:

{% hint style="success" %}
Analytics удобно использовать, когда нужно:

* смотреть общую картину по трафику и кампаниям
* разбирать эффективность по этапам воронки
* сравнивать результаты по выбранным параметрам
* готовить отчёты и искать точки роста
{% endhint %}
