# Campaigns

> ### Campaigns - это раздел Tracker для создания и управления рекламными кампаниями.

<div align="left" data-with-frame="true"><figure><img src="../../../.gitbook/assets/Frame 2104.png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
С его помощью можно:

\- создавать новые рекламные кампании

\- задавать путь пользователя от клика до приёмщика

\- настраивать параметры трекинга и фильтры

\- получать ссылки для запуска трафика

\- контролировать метрики по конкретной кампании
{% endhint %}

### Как работает Campaigns:

{% hint style="info" %}
В этом разделе задаётся путь пользователя от клика до лендинга, бота, канала или личного аккаунта.
{% endhint %}

{% hint style="info" %}
Здесь же настраиваются источник трафика, маршрут перехода и правила обработки трафика.
{% endhint %}

### Как использовать Campaigns:

{% stepper %}
{% step %}
{% hint style="info" %}
**Создайте новую кампанию**

Сначала в Campaigns создаётся новая кампания.

На этом этапе задаются базовые параметры запуска.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Настройте маршрут трафика**

Затем выбираются домен, лендинг, источник и способ перехода пользователя.

Так система понимает, как вести пользователя дальше.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Запустите и анализируйте трафик**

После запуска кампания начинает собирать события и метрики.

Дальше результаты анализируются в Dashboards, Analytics и Logs.
{% endhint %}
{% endstep %}
{% endstepper %}

### Подробнее:

<details>

<summary>Что управляется в Campaigns</summary>

{% hint style="info" %}
В этом разделе обычно настраивают:

* тип кампании и источник трафика
* домен и лендинг
* параметры и фильтры трекинга
* маршрут пользователя после клика
* ссылки для запуска трафика
{% endhint %}

</details>

<details>

<summary>Какие типы кампаний доступны</summary>

{% hint style="info" %}
**Not Organic**

Используется для платного трафика.

Подходит для Facebook, Google и других источников.

Передаёт и сохраняет параметры трекинга.

Помогает анализировать эффективность рекламы.
{% endhint %}

{% hint style="warning" %}
**Organic**

Используется для органического трафика.

Трекинговые параметры обычно не передаются.
{% endhint %}

</details>

<details>

<summary>Что видно в списке кампаний</summary>

{% hint style="info" %}
В списке отображаются все созданные кампании.

Каждая кампания показана отдельной карточкой.
{% endhint %}

{% hint style="info" %}
В карточке видны:

* статус кампании
* тип трафика и источник
* домен и лендинг
* подключения: Invite Bot, DM bot, Telegram-канал
* buyer, назначенный на кампанию
* метрики `SUBS`, `DIA`, `REG`, `DEP`
{% endhint %}

{% hint style="info" %}
Метрики обновляются по событиям, которые вы отправляете в Tracker.

Проверьте интеграции, если значения не растут.
{% endhint %}

</details>

<details>

<summary>Какие действия доступны</summary>

{% hint style="info" %}
Действия доступны прямо из карточки кампании:

* Links — получить ссылки для запуска трафика
* Edit — открыть настройки кампании
* Duplicate — создать копию кампании
* Stop — остановить кампанию
{% endhint %}

{% hint style="warning" %}
`Stop` останавливает кампанию, но не удаляет её.

Используйте это, чтобы безопасно завершить закуп.
{% endhint %}

</details>

### Где удобно использовать Campaigns:

{% hint style="success" %}
Campaigns удобно использовать, когда нужно:

* создать новый запуск под источник трафика
* связать клик, лендинг и приёмщик лидов
* разделить платный и органический трафик
* получить ссылки и контролировать метрики по кампании
{% endhint %}
