# Как создать кампанию

> ### Как создать кампанию - это инструкция по запуску новой кампании в Tracker.

{% hint style="info" %}
С её помощью можно:

* создать новый запуск под нужный источник трафика
* настроить маршрут пользователя от клика до приёмщика
* заполнить все обязательные параметры кампании
* подготовить кампанию к запуску трафика
{% endhint %}

### Как работает создание кампании:

{% hint style="info" %}
Кампания создаётся в разделе Campaigns.

После сохранения она появляется в общем списке и становится доступной для запуска.
{% endhint %}

### Как создать кампанию:

{% stepper %}
{% step %}
{% hint style="info" %}
*   #### **Откройте список Campaigns**

    Перейдите в `Tracker → Campaigns`.

    ![Список Campaigns](<../../../.gitbook/assets/Frame 2104.png>)
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Нажмите Create campaign**

    Нажмите `Create campaign` в правом верхнем углу.

    ![Кнопка Create campaign](<../../../.gitbook/assets/Frame 2105.png>)
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Пройдите все этапы настройки**

    В открывшемся окне заполните все разделы кампании.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
*   #### **Сохраните кампанию**

    После сохранения кампания появится в списке `Campaigns`.

    Теперь её можно запускать и лить трафик.
{% endhint %}
{% endstep %}
{% endstepper %}

* кампания появляется в общем списке

<summary>Важные особенности</summary>

{% hint style="warning" %}
* перед запуском проверьте, что все обязательные разделы заполнены
* без корректных источников и параметров статистика может собираться неправильно
* перед заливом трафика лучше пройти раздел Test
{% endhint %}

### Где удобно использовать эту инструкцию:

{% hint style="success" %}
Эта инструкция удобна, когда нужно:

* быстро создать новую кампанию
* не пропустить обязательные этапы настройки
* подготовить запуск под новый источник трафика
* проверить, что кампания готова к запуску
{% endhint %}
