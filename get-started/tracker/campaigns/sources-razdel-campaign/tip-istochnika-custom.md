# Тип источника Custom

> ### Custom - это универсальный тип источника в Tracker.

{% hint style="info" %}
С его помощью можно:

* запускать тестовый и внешний трафик
* использовать собственные параметры в ссылке
* проверять логику маршрутизации без готовой интеграции
* работать с нестандартными сценариями и сторонними источниками
* использовать auto redirect после клика
*


{% endhint %}

### Как работает источник Custom:

{% hint style="info" %}
Источник Custom нужен для сценариев, где нет готовой интеграции с рекламной платформой.
{% endhint %}

{% hint style="info" %}
Через него обычно запускают тестовый, внешний или полностью кастомный трафик.
{% endhint %}

### Как настроить источник Custom:

{% stepper %}
{% step %}
{% hint style="info" %}
**Создайте кампанию**

Сначала в Tracker создаётся кампания.

Внутри неё задаётся логика маршрутизации и учёта трафика.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Выберите тип источника Custom**

После этого в разделе Sources выберите тип `Custom`.

Он служит универсальной точкой входа для нестандартного трафика.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Проверьте передачу параметров**

Через Custom удобно тестировать ссылку, параметры и общую логику запуска.

Это помогает убедиться, что трафик корректно попадает в Tracker.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Настройте дальнейший маршрут пользователя**

Если включён `Auto redirect`, пользователь автоматически уходит по следующему сценарию.

Маршрут редиректа задаётся в настройках кампании.
{% endhint %}
{% endstep %}
{% endstepper %}

<summary>Когда использовать Custom</summary>

{% hint style="info" %}
Источник `Custom` нужен, когда вы хотите:

* протестировать кампанию до запуска
* подключить сторонний источник трафика
* передавать свои параметры в ссылке
* запускать ручные сценарии
* работать без готового шаблона интеграции

Если источник трафика не подходит под готовые типы, используйте `Custom`.
