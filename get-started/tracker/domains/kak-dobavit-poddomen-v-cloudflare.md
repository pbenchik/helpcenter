# Как добавить поддомен в Cloudflare

> ### Как добавить поддомен в Cloudflare - это инструкция по созданию отдельного адреса внутри уже подключённого домена.

{% hint style="info" %}
С её помощью можно:

* создать отдельный адрес для кампании или лендинга
* направить поддомен на Chatterfy
* подготовить поддомен к SSL и добавлению в Tracker
* разделить разные направления трафика без смены основного домена
{% endhint %}

### Видеоинструкция:

{% hint style="info" icon="plus" %}
В видео показано, как создать поддомен внутри Cloudflare и направить его на Chatterfy.

Подойдёт, если основной домен уже подключён и нужен отдельный адрес для кампании или лендинга.

{% embed url="https://youtu.be/bHK-fuIVYTU" %}
{% endhint %}

### Как работает подключение поддомена:

{% hint style="info" %}
Поддомен в Cloudflare — это отдельный адрес внутри уже подключённого домена.
{% endhint %}

{% hint style="info" %}
Он нужен, если вы хотите использовать не основной домен, а адрес вида `offer.example.com`.
{% endhint %}

### Как добавить поддомен в Cloudflare:

{% stepper %}
{% step %}
{% hint style="info" %}
**Откройте нужный домен в Cloudflare**

Перейдите в Cloudflare.

Выберите домен, внутри которого хотите создать поддомен.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Перейдите в DNS → Records**

Откройте раздел DNS-записей выбранного домена.

Именно здесь создаются новые адреса внутри домена.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Создайте запись для поддомена**

Укажите такие значения:

* `Type` — `CNAME`
* `Name` — имя поддомена, например `offer`
* `Target` — `nemo.chatterfy.ai`

После сохранения поддомен будет указывать на Chatterfy.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Проверьте SSL для домена**

Откройте раздел `SSL/TLS → Overview`.

Убедитесь, что для домена включён режим `Flexible`.

Если нужен отдельный чек-лист, используйте статью [Как настроить SSL](kak-nastroit-ssl.md).
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Добавьте поддомен в Chatterfy**

Перейдите в `Tracker → Domains`.

Нажмите `Create domain`.

В поле `Domain` укажите полный поддомен, например `offer.example.com`.

Дальше используйте ту же логику, что и для обычного домена: [Как добавить домен в Chatterfy](kak-dobavit-domen-v-chatterfy.md).
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Проверьте результат**

Откройте поддомен в браузере.

Убедитесь, что страница открывается по `HTTPS` и без ошибок сертификата.
{% endhint %}
{% endstep %}
{% endstepper %}

### Подробнее:

<details>

<summary>Что настраивается для поддомена</summary>

{% hint style="info" %}
В этой настройке обычно делают:

* выбор уже подключенного домена в Cloudflare
* создание DNS-записи для поддомена
* привязку поддомена к `nemo.chatterfy.ai`
* проверку SSL для основного домена
* подготовку поддомена к добавлению в Chatterfy
{% endhint %}

</details>

<details>

<summary>Когда использовать эту инструкцию</summary>

{% hint style="info" %}
Эта инструкция нужна, когда вы хотите:

* создать отдельный адрес внутри основного домена
* использовать поддомен для кампании или лендинга
* разделить разные направления трафика
* не менять основной адрес сайта
* быстро подключить новый адрес к Tracker
{% endhint %}

</details>

<details>

<summary>Что проверить перед настройкой</summary>

{% hint style="warning" %}
Перед настройкой проверьте:

* основной домен уже добавлен в Cloudflare
* у вас есть доступ к нужной зоне в Cloudflare
* вы создаёте именно поддомен, а не основной домен
{% endhint %}

{% hint style="info" %}
Если основной домен ещё не подключён, сначала выполните шаги из статьи [Как добавить домен в Cloudflare](kak-dobavit-domen-v-cloudflare.md).
{% endhint %}

</details>

<details>

<summary>Какую роль поддомен играет в системе</summary>

{% hint style="warning" %}
Сначала вы открываете в Cloudflare домен, внутри которого хотите создать поддомен.

Поддомен всегда создаётся внутри уже подключенной DNS-зоны.
{% endhint %}

{% hint style="warning" %}
Дальше вы добавляете отдельную запись для нового адреса.

Именно она направляет поддомен на Chatterfy.
{% endhint %}

{% hint style="warning" %}
После этого нужно убедиться, что для домена корректно работает SSL.

Без этого поддомен может открываться с ошибками.
{% endhint %}

{% hint style="warning" %}
Когда DNS уже настроен, поддомен можно добавить в Tracker.

После этого он станет доступен для кампаний и лендингов.
{% endhint %}

</details>

<details>

<summary>Какие поля нужны</summary>

{% hint style="info" %}
`Type` — тип DNS-записи.

Для поддомена используйте `CNAME`.
{% endhint %}

{% hint style="info" %}
`Name` — имя поддомена без основного домена.

Например, для `offer.example.com` укажите `offer`.
{% endhint %}

{% hint style="info" %}
`Target` — адрес назначения для поддомена.

Укажите `nemo.chatterfy.ai`.
{% endhint %}

{% hint style="info" %}
`Domain` — полный адрес поддомена в Chatterfy.

Например, `offer.example.com`.
{% endhint %}

</details>

<details>

<summary>Что проверить после настройки</summary>

{% hint style="info" %}
После сохранения проверьте:

* запись `CNAME` создана корректно
* поддомен указывает на `nemo.chatterfy.ai`
* SSL работает без ошибок
* поддомен добавлен в Chatterfy
* адрес открывается по `HTTPS`
{% endhint %}

{% hint style="info" %}
Для поддомена не нужно заново подключать nameservers.

Достаточно создать DNS-запись внутри уже добавленного домена.
{% endhint %}

</details>

### Где удобно использовать эту инструкцию:

{% hint style="success" %}
Эта инструкция удобна, когда нужно:

* создать отдельный адрес для новой кампании
* разделить трафик по разным поддоменам
* быстро подключить новый лендинг без смены основного домена
* подготовить поддомен для SSL и добавления в Tracker
{% endhint %}
