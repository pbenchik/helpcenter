# Dashboards

> ### Dashboards - это сводная аналитика в Tracker. Она нужна для быстрого контроля кампаний без глубокого погружения в таблицы.

***

### Основные показатели:

{% hint style="info" %}
В верхней части Dashboards отображаются ключевые метрики:

* **Clicks** — клики по кнопке перехода в Telegram на лендинге.
* **Subscribers** — подписки на канал или запуск бота.
* **Dialogues** — пользователи, по которым получено событие `contact`.
* **Registration** — успешные регистрации.
* **FD** — первые депозиты.
* **RD** — повторные депозиты.

Метрики обновляются автоматически, когда приходят события.
{% endhint %}

{% hint style="info" %}
<mark style="color:$primary;">Используйте фильтры, чтобы смотреть статистику по конкретным связкам.</mark>
{% endhint %}

### Графики аналитики:

{% hint style="info" %}
Ниже идут графики движения пользователя по воронке. Они показывают динамику по кампаниям и выбранным фильтрам.

Dashboards отображает:

* **Page Views** — открытия лендинга.
* **CTR** — соотношение просмотров и кликов.
* **Views → Sub** — конверсия из просмотра в подписку.
* **Clicks → Sub** — конверсия из клика в подписку.
* **Subscribes / Unsubscribes / Net Subscribes** — подписки, отписки, чистый рост.
* **Net Clicks → Sub** — конверсия с учётом уникальных кликов.
* **Sub → Dia / Dialogues** — конверсия и объём диалогов (`contact`).
* **Dia → Reg / Registrations** — конверсия и объём регистраций.
* **Reg → FD / FD** — конверсия и первые депозиты.
* **Dia → FD** — конверсия диалог → первый депозит.
* **FD → Uniq RD / Unique RD** — переход к уникальным повторным депозитам.
* **FD → RD / RD** — переход к повторным депозитам и их объём.
{% endhint %}
