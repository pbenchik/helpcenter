# Custom

> ### **Custom** — это режим загрузки собственного лендинга в Tracker.

{% hint style="info" %}
Он нужен, если вы хотите использовать готовую страницу вместо стандартного шаблона.

Такой вариант подходит для кастомного дизайна, своей структуры и нестандартной логики страницы.

*

    <div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image 32591.png" alt=""><figcaption></figcaption></figure></div>
{% endhint %}

### Как работает Custom landing:

{% stepper %}
{% step %}
### Создаётся landing

{% hint style="info" %}
Сначала в разделе **Tracker → Landings** создаётся новый лендинг.

После этого открывается его карточка для дальнейшей настройки.
{% endhint %}
{% endstep %}

{% step %}
### Выбирается режим Custom

{% hint style="info" %}
Дальше в настройках лендинга выбирается режим **Custom**.

Это переключает страницу с шаблонного режима на загрузку собственного архива.
{% endhint %}
{% endstep %}

{% step %}
### Загружается архив

{% hint style="info" %}
После этого в систему загружается `.zip`-архив с готовым лендингом.

Tracker использует содержимое архива как основу страницы.
{% endhint %}
{% endstep %}

{% step %}
### Лендинг подключается к кампании

{% hint style="info" %}
Когда архив сохранён, лендинг можно использовать в Campaigns.

Дальше система будет открывать именно вашу кастомную страницу.
{% endhint %}
{% endstep %}
{% endstepper %}

### Основные правила Custom:

<details>

<summary>Требования к архиву</summary>

{% hint style="info" %}
Архив должен быть полностью готов к загрузке до добавления в Tracker.

Базовые требования:

* формат архива — `.zip`
* в корне архива должен лежать `index.html`
* все стили должны быть внутри архива
* все изображения должны быть внутри архива
* все скрипты должны быть внутри архива
{% endhint %}

</details>

<details>

<summary>Что важно при загрузке</summary>

{% hint style="info" %}
Tracker не собирает страницу за вас.

Он просто использует уже готовый архив как кастомный лендинг.

Поэтому страницу нужно полностью подготовить заранее.
{% endhint %}

</details>

<details>

<summary>Как работает кнопка перехода</summary>

{% hint style="info" %}
Чтобы Tracker фиксировал переход пользователя, элемент перехода должен содержать атрибут `tracker`.

Таких элементов на странице может быть несколько.

Все клики по ним фиксируются системой как переходы внутри лендинга.
{% endhint %}

</details>

<details>

<summary>Что нельзя делать</summary>

{% hint style="warning" %}
Не добавляйте в элемент с атрибутом `tracker` прямую ссылку и поле `href`.

Переход в Telegram Tracker формирует автоматически.
{% endhint %}

</details>

{% hint style="info" %}
Базовая логика Custom простая: **создать landing → выбрать Custom → загрузить `.zip` → использовать лендинг в Campaigns**.
{% endhint %}
