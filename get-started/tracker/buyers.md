# Buyers

> ### Buyers - это раздел для разграничения доступа в Tracker.

{% hint style="info" %}
С его помощью можно:

* разделять кампании между байерами
* ограничивать доступ к чужим данным
* назначать Buyer Team Lead на группу байеров
* разделять аналитику по командам
{% endhint %}

### Как работает Buyers:

{% hint style="info" %}
Раздел помогает разделять кампании, аналитику и команды байеров.
{% endhint %}

{% hint style="info" %}
Через него настраивается, кто видит свои кампании, а кто получает доступ к команде целиком.
{% endhint %}

### Когда использовать Buyers:

{% stepper %}
{% step %}
{% hint style="info" %}
**Назначьте роль Buyer**

Используйте эту роль, если пользователь запускает свои рекламные кампании и должен видеть только свои данные.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Назначьте роль Buyer Team Lead**

Используйте эту роль, если пользователь должен видеть кампании и аналитику своей команды байеров.
{% endhint %}
{% endstep %}

{% step %}
{% hint style="info" %}
**Разделите кампании по пользователям**

Для корректной аналитики и доступа закрепляйте отдельные кампании за каждым Buyer.
{% endhint %}
{% endstep %}
{% endstepper %}

### Полезная информация:

<details>

<summary>Когда нужен раздел Buyers</summary>

{% hint style="info" %}
Используйте этот раздел, если нужно:

* ограничить доступ к кампаниям
* разделить аналитику между байерами
* назначить Team Lead на группу байеров
* убрать доступ к чужим данным
{% endhint %}

</details>

<details>

<summary>Какие роли поддерживаются</summary>

{% hint style="info" %}
В Tracker доступны две роли:

* `Buyer`
* `Buyer Team Lead`
{% endhint %}

</details>

<details>

<summary>Buyer</summary>

{% hint style="info" %}
`Buyer` — это пользователь, который запускает рекламные кампании.
{% endhint %}

{% hint style="info" %}
Права Buyer:

* имеет доступ к Tracker
* видит только свои кампании
* видит только свою статистику
* не видит кампании других пользователей
* работает только со своими или назначенными на него кампаниями
{% endhint %}

{% hint style="warning" %}
Один Buyer может быть назначен только под одного Team Lead.
{% endhint %}

</details>

<details>

<summary>Buyer Team Lead</summary>

{% hint style="info" %}
`Buyer Team Lead` — это руководитель группы байеров.
{% endhint %}

{% hint style="info" %}
Права Buyer Team Lead:

* имеет доступ к Tracker
* видит все кампании своих байеров
* может просматривать статистику и аналитику своих байеров
* может редактировать кампании своих байеров
* управляет байерами, которые находятся у него в команде
{% endhint %}

{% hint style="info" %}
Team Lead получает доступ ко всей активности закреплённых за ним байеров.
{% endhint %}

</details>

<details>

<summary>Доступ к Spaces</summary>

{% hint style="info" %}
По умолчанию роли `Buyer` и `Buyer Team Lead` не имеют доступа к Spaces.

Они работают только с Tracker и связанными с ним разделами.
{% endhint %}

</details>

<details>

<summary>Рекомендации по работе</summary>

{% hint style="info" %}
Рекомендуется создавать отдельные кампании для каждого Buyer.

Это помогает:

* корректно разделять статистику
* ограничивать доступ к данным
* упрощать анализ по каждому байеру
* не смешивать аналитику разных команд
{% endhint %}

</details>

### Где удобно использовать Buyers:

{% hint style="success" %}
Buyers удобно использовать, когда нужно:

* разделить доступ к Tracker между разными людьми
* дать Team Lead доступ к группе байеров
* разнести кампании и аналитику по командам
* сохранить чистую структуру доступа и статистики
{% endhint %}
